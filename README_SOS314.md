# SOS314 · 문제인식/자르기/문항분석 완전 분리

## 실제 처리 순서

1. AI 문제인식
   - 시험지에서 문항번호, 페이지, 검수용 위치만 저장
   - 정답, 단원, 유형, 난이도, DNA 분석은 실행하지 않음
   - 문항 이미지도 아직 저장하지 않음

2. AI 자르기
   - 1단계에서 확정된 문항만 이미지로 잘라 저장
   - 전체 자르기 후 잘못된 문항만 수동 수정
   - 자르기 통과 버튼은 분석을 자동 실행하지 않음

3. AI 문항분석
   - 자르기 검수가 완료된 이미지로만 정답, 단원, 유형, 난이도, DNA 분석
   - 관리자가 `AI 문항분석 시작` 버튼을 눌러야 실행

## 함께 수정한 오류

- `/api/analysis/start`의 자르기+분석 동시 `Promise.all` 제거
- 클라이언트의 `recognition-only` 모드와 강제 재인식 값 전달
- 문제인식 통과 시 자동 자르기 제거
- 자르기 통과 시 자동 분석 제거
- 문항이 존재한다는 이유만으로 재접속 시 2단계로 이동하던 판정 제거
- 수동 인식 문항을 자르기 완료로 미리 표시하던 값 제거
- 인식 단계 신규 문항 상태를 `WAITING`으로 통일

## 배포 후 기존 시험지

이전 버전에서 이미 자르기·분석값이 섞인 시험지는 `AI 문제인식 다시 하기`를 실행하면
미등록 문항을 1단계 인식 데이터부터 새로 구성할 수 있습니다.
문제은행에 이미 등록된 문항은 초기화 API의 기존 보존 정책을 따릅니다.

추가 SQL은 없습니다.
