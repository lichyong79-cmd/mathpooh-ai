# SOS239 · 수동 문제인식 + 해설 다시 자동 매칭

## 1) 1단계 문제인식 수동 보정
- AI 문제인식 화면에서 `＋ 수동 인식`을 켤 수 있습니다.
- 문항번호를 입력하고 시험지 PDF의 실제 문항 영역을 드래그합니다.
- 이미 존재하는 문항번호면 해당 인식 좌표를 수정합니다.
- 누락된 문항번호면 analysis_questions에 새 문항 후보를 추가합니다.
- 수동 인식 좌표는 `recognition_manual/crop_manual`로 표시되어 2단계 전체 자르기가 해당 좌표를 그대로 사용합니다.
- PDF 텍스트 앵커가 없는 문항도 수동 인식된 경우 1단계 통과를 막지 않습니다.

## 2) 공식 해설만 다시 자동 매칭
- 3단계 문항 상세의 공식 해설 패널에 `↻ 해설 다시 자동 매칭` 버튼을 추가했습니다.
- 현재 문제 이미지, Problem DNA, 분석 결과는 다시 돌리지 않습니다.
- 해설 PDF의 해당 문항번호 앵커만 다시 찾아 문항별 공식 해설 이미지를 덮어씁니다.
- 자동으로 번호를 찾지 못하면 기존 `해설 PDF에서 직접 긁기` 기능을 그대로 사용합니다.
