# SOS126 - 실전모의고사 전체 재분석 속도 개선

## 변경 전
- 브라우저가 1번부터 마지막 문항까지 순차 반복
- 매 문항마다 API 호출
- 매 호출마다 시험지/해설지 PDF를 다시 AI에 전송
- 30문항이면 PDF 전송 및 AI 요청도 최대 30회

## 변경 후
- 전체 재분석 버튼은 API를 단 한 번 호출
- 시험지/해설지 PDF도 한 번만 전송
- AI가 전체 문항을 한 번에 분석
- 분석 결과를 Supabase에 한 번의 upsert로 저장
- 개별 `이 문항 재분석` 기능은 기존처럼 유지

## 기대 효과
전체 재분석의 중복 PDF 로딩, 서버 왕복, AI 요청을 제거해 기존보다 크게 단축됩니다.
실제 시간은 PDF 페이지 수와 OpenAI 응답 속도에 따라 달라집니다.
