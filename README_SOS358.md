# SOS358 · 시험 답안 0개/중복 응시 근본 수정

## 운영 데이터에서 확인된 원인

- 권우섭: 동일 시험 응시행 12개
- 최현슬: 동일 시험 응시행 7개
- 여러 행 때문에 `.maybeSingle()`이 실패하여 자동저장이 진행되지 않았습니다.

## 코드 수정

- 저장·제출 요청은 화면이 시작할 때 받은 `attemptId` 한 건만 갱신합니다.
- 시험 시작의 연속 실행을 브라우저에서 즉시 차단합니다.
- 답 입력이 0.8초 멈추면 저장하고, 기존 10초 저장도 안전망으로 유지합니다.
- 관리자 일시정지/재개/강제제출을 시험 화면이 3초 이내 동기화합니다.
- 기존 중복행이 있어도 답안 수가 가장 많은 정상 행을 학생·관리자·학부모 화면에서 하나만 사용합니다.
- 결과 조회 중 재채점하여 관리자 확정값을 덮는 동작도 제거된 SOS357을 포함합니다.

## 필수 SQL

배포 직후 Supabase SQL Editor에서 `supabase-sos358-exam-attempt-unique.sql`을 한 번 실행합니다.

SQL은 중복행 중 답안이 가장 많은 정상 행을 남기고 로그를 그 행으로 연결한 뒤,
`(exam_id, student_id)` UNIQUE 인덱스를 추가합니다.
