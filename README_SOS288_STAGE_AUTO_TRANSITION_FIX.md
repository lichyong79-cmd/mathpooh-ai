# SOS288 · 진단/오답 완료 후 다음 단계 자동 전환 수정

## 증상
- 진단 완료 후 다음 진단/1차훈련이 서버에서 생성되어도 학생 화면이 기존 완료 세션에 남음.
- 진단 오답 교정 완료 후 1차훈련으로 넘어가려면 브라우저 새로고침이 필요함.

## 원인
단계 완료 API는 다음 세션 id를 응답으로 돌려주고 있었지만, 학생 Workspace의 `load()`는 그 id를 사용하지 않았습니다.
`load()`가 기존 `activeId`를 유지하고, 이후 `useEffect`가 열린 세션을 다시 판단하는 2단계 구조여서 완료 직후 상태 갱신 순서에 따라 기존 세션 화면에 남을 수 있었습니다.
브라우저 새로고침 시에는 activeId가 비어 있으므로 다음 열린 세션이 정상 선택되어 증상이 사라졌습니다.

## 수정
- `load(preferredActiveId?)` 지원.
- 단계 완료 응답의 `next.id`, `ai.session.id`, `ai.sessionId` 등을 즉시 추출.
- 진단/훈련/오답 완료 콜백은 `refreshAfterStage(json)`을 통해 서버가 알려준 다음 세션을 우선 active로 선택.
- 다음 세션 id가 없는 경우 기존 열린 세션 자동선택 로직을 그대로 fallback으로 사용.

## 기대 동작
진단 → (오답 교정) → 2차진단 또는 1차훈련이 생성되면 F5 없이 즉시 다음 단계 화면으로 이동합니다.
