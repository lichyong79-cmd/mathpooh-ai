# SOS v0.5 통합 데모

관리자/학생 화면 전환이 포함된 모집 시연용 통합 화면입니다.

## 포함 화면
- 관리자: 대시보드, 학생관리, 실전모의고사, 훈련 문제은행, AI 분석관리, SOS 추천, 결과·이력
- 학생: 대시보드, 실전모의고사, SOS 단일 흐름, 결과
- SOS 흐름: 공략문항 → 진단3 → 필요시 추가진단 → 훈련10 → 필요시 추가훈련 → 완료

## 실행
```bash
npm install
npm run build
npm run dev
```

현재 화면 데이터는 모집 시연을 위한 데모 데이터입니다. 기존 Supabase 환경변수는 그대로 유지됩니다.
