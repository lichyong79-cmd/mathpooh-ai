# SOS302 · 객관식 정답번호 오인 방지

- 원문 객관식의 정답번호 1~5를 생성문항의 수학적 답으로 복사하지 못하게 했습니다.
- AI 유사문항에서 보기·선택지·`보기와 동일한 형태` 문구를 금지합니다.
- 기호식 결과는 정수 매개변수를 묻는 동치 질문으로 바꾸도록 강제합니다.
- 밑 없는 `log`는 상용로그이며 `log 6`을 밑 6의 로그로 해석하지 않도록 독립검수 규칙을 추가했습니다.
- 로그 문항은 최종 재풀이 추론 강도를 `high`로 높입니다.

이미 배정된 잘못된 문항은 자동 변경하지 않습니다. 해당 학생 기록은 관리자 답안관리에서 별도로 정정해야 합니다.
