# SOS340 학부모 신규가입 안내 및 계정 분리 표시

## 계정 원칙

- 학부모 계정과 학생 계정은 서로 다른 로그인 계정입니다.
- 학부모 가입에서 입력한 비밀번호는 학부모 로그인에만 사용합니다.
- 새 자녀 계정을 만들 때 학생용 비밀번호를 별도로 설정합니다.
- 기존 자녀 연결은 학생의 기존 계정과 비밀번호를 변경하지 않습니다.

## 화면 개선

- 가입 전과 가입 완료 화면에 `sos.mathpooh.com` 전용 계정이며 기존 `mathpooh.com` 계정과는 별개라는 안내를 추가했습니다.
- 학부모 신규가입 화면에 `학부모 가입 → 자녀 연결 → 회차 신청` 순서를 표시했습니다.
- 학부모 비밀번호와 학생 비밀번호가 별도라는 안내를 가입 화면에 추가했습니다.
- 가입 직후 즉시 이동하지 않고, 다음 네 단계가 표시되는 가입 완료 화면을 추가했습니다.
- 새 자녀 계정 생성 화면에 학생 비밀번호 확인 입력란을 추가했습니다.
- 기존 자녀 연결 시 학생 비밀번호가 바뀌지 않는다는 안내를 추가했습니다.

## 검증

- Next.js 컴파일 성공
- TypeScript 검사 성공
- 정적 페이지 생성은 로컬 Supabase 환경변수 부재로 중단됨
