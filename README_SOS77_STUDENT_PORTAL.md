# SOS77 학생 온라인 시험 포털

## 배포 전 1회 실행

Supabase SQL Editor에서 `supabase-v2.3-student-exam-portal.sql` 전체를 실행합니다.

Vercel에는 기존과 동일하게 다음 환경변수가 있어야 합니다.

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`

## 주소

- `/` 학생 홈·응시
- `/admin` 관리자
- `/p` 학부모 페이지 준비 화면
- `/login` 공통 로그인

## 학생 계정

- 학생관리에서 학생 등록 시 전화번호 아이디 계정이 자동 생성됩니다.
- 초기 비밀번호는 전화번호 뒤 4자리입니다.
- Supabase의 최소 비밀번호 길이 제한은 서버에서 내부 변환하여 처리하므로 학생은 뒤 4자리만 입력합니다.
- 학생은 우측 상단에서 비밀번호를 변경할 수 있습니다.
- 관리자는 학생 상세의 `비밀번호 초기화`로 뒤 4자리 비밀번호로 되돌릴 수 있습니다.

## 시험 공개

관리자 `실전 모의고사 > 시험 목록`에서 시험지와 전체 정답을 등록한 뒤 `학생 공개`를 누릅니다.
학생은 본인 학년 또는 `전체` 대상의 공개 시험을 볼 수 있습니다.

## 응시 화면

- 시험지 PDF 왼쪽, Web OMR 오른쪽
- 전체 제한시간 타이머
- 10초 자동 저장 및 수동 저장
- 객관식 1~5, 단답형 숫자 입력
- 미입력 문항 표시와 제출 전 경고
- 시간 종료 시 자동 제출
- 제출 즉시 자동 채점
