# SOS 181 - 전체 8단계 난이도 재판정

- 관리자 확정(admin_fixed) 문항은 전체 재판정에서 제외하고 보존
- 과거 1~5 관리자 확정 데이터는 보존만 하고 AI reference로 사용하지 않음
- 새 8단계(sos8-v1) 관리자 확정 문항만 단계별 최대 3개 reference로 사용
- 미확정 ACTIVE 문항을 20개씩 배치 재판정
- 진행률: 완료/전체, 성공, 실패, 관리자 확정 제외 수 표시
- 완료 후 문제 목록을 재로딩하여 8단계 분포 갱신
- 전체 TS/TSX의 use client 위치 오류 자동 정리
