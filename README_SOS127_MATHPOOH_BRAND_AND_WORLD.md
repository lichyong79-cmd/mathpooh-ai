# SOS127 매쓰푸 브랜드·SOS 월드 적용

## 반영 내용
- 기존 곰 이모지 제거
- 사용자가 제공한 흰 후드 매쓰푸를 학생/공통 로딩 캐릭터로 적용
- 사용자가 제공한 안경 원장푸우를 관리자 AI 작업 로딩에 적용
- AI 분석, 전체 재분석, 문제 자르기, 저장 등 기존 공통 로딩 구조 유지
- 학생 페이지 상단에 1차 SOS WORLD 홈 추가
  - 실전모의고사
  - SOS 공략실
  - 성장 분석실
  - SOS 광장
- SOS 캠퍼스, 성장나무, 매쓰푸 애니메이션 장면 적용
- 모바일에서는 SOS WORLD를 간단한 메뉴형 화면으로 축소
