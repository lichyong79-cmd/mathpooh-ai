# SOS357 관리자 결과 ↔ 학생 결과 단일 원본 연결

## 수정 내용

- 관리자 결과 수정에서 저장한 `exam_attempts.score`, 정답 수, 오답/미응답 번호를 학생 결과 화면이 그대로 사용합니다.
- 학생 결과 조회, 관리자 결과 조회, 학부모 결과 조회가 화면을 열 때 답안을 재채점하며 저장값을 덮어쓰던 동작을 제거했습니다.
- 같은 학생·시험에 과거 중복 응시행이 있더라도 최신 관리자 채점 시각의 결과 한 건만 관리자/학생 화면이 동일하게 선택합니다.
- 자동 재채점은 학생 제출, 관리자 결과 저장, 관리자가 명시적으로 실행하는 재분석에서만 수행됩니다.
- 따라서 관리자 화면에서 확정한 최현슬 학생의 점수가 학생 화면에서 다시 0점으로 바뀌지 않습니다.

## 배포 직후

이미 0점으로 덮인 학생은 관리자 결과 수정에서 답안을 확인하고 `수정 결과 저장`을 한 번 누르면 확정값이 저장되며, 이후 학생 화면에 동일하게 표시됩니다.

## 확인

- `npx tsc --noEmit` 통과
