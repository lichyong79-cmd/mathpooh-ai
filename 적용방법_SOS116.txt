SOS116 관리자 UI 가독성 및 메뉴 계층 개선

적용 내용
- MATSPU 오타를 MATHPOOH로 수정
- 브랜드 표시: MATHPOOH SOS / SCORE OPTIMIZATION SYSTEM
- 상위 메뉴 분류를 진한 녹색 헤더로 표시
- 하위 메뉴를 들여쓰기, 연결선, 연한 배경으로 명확히 구분
- 현재 선택 메뉴에 녹색 바와 현재 배지 표시
- 사이드바 폭과 메뉴 글씨 확대
- 본문 제목, 설명, 탭, 표, 입력칸, 버튼 글씨 확대
- 접힌 사이드바에서도 아이콘 중심 구조 유지

적용 방법
1. ZIP 압축을 프로젝트에 덮어씁니다.
2. npm install
3. npm run build
4. git add .
5. git commit -m "SOS116 관리자 UI 가독성 개선"
6. git push
