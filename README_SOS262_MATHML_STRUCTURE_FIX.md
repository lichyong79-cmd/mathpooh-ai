# SOS262 — MathML 구조 교정

1. 이미 생성된 AI 문항도 화면에서 구조 보정:
   - 조각함수 f(x)={... (x≠0), ... (x=0)}를 큰 왼쪽 중괄호 + 2행 mtable로 재구성
   - 최상위 "/" 나눗셈을 mfrac 분수로 변환
2. 신규 3제/2차훈련 생성 검증 강화:
   - <mo>/</mo>가 남으면 생성 실패
   - 분수 문제인데 mfrac 없으면 실패
   - 조각함수인데 mtable/큰 중괄호 없으면 실패
3. 제목과 유형명 사이 간격/정렬 보정.
4. SOS261 학습 흐름은 변경하지 않음.
5. SQL 없음.
