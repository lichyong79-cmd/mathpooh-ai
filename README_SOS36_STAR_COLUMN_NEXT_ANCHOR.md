# SOS36 · 별 + 같은 단 다음 별 자르기

## 변경 내용
- AI가 crop 사각형을 직접 반환하지 않음
- AI는 각 문항의 `★ 중심 좌표`, `왼쪽/오른쪽/전체 단`, `실제 문항 내용 끝점`만 반환
- 서버 코드가 같은 페이지·같은 단의 다음 ★를 검색
- 최종 하단은 `AI 내용 끝점`과 `같은 단 다음 ★ 직전` 중 더 위쪽 사용
- 왼쪽 문항과 오른쪽 문항이 서로의 경계를 침범하지 않도록 단 폭을 코드로 고정
- 저장된 ai_result에 star_anchor, content_bottom, next_star_y 디버그 값을 보관
- SOS35 완전삭제 기능 포함

## 테스트 순서
1. SOS35 SQL을 아직 실행하지 않았다면 `supabase-v2.1-source-file-cascade-delete.sql` 실행
2. 기존 시험지 삭제
3. 새로고침
4. 별표 PDF 신규 등록
5. 전체 AI 분석 시작
6. 7번, 19번, 20번의 시작점과 좌우 단 확인

별표는 반드시 각 실제 문항의 시작 바로 위에 넣고, 예제에는 넣지 않습니다.
