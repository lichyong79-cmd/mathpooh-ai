# SOS209 · 진단완료 → 훈련 자동선정 + 시작 전 생성취소

SOS208 누적본.

변경:
- 학생이 진단 3문항을 모두 제출하면 서버가 즉시 자동채점.
- 채점 직후 갱신된 '해당 소단원 학생 미터'를 사용해 훈련 10문항을 자동선정.
- 훈련은 같은 과목 + 같은 소단원 안에서만 고름.
- 세부 유형/Problem DNA가 원 SOS_NO1과 가까운 문항을 우선하고, 그 안에서 학생 미터와 난이도를 맞춤.
- 자동 생성된 훈련은 즉시 ASSIGNED 되어 학생 나의 SOS에 나타남.
- 같은 진단에서 훈련이 이미 생성돼 있으면 중복 생성하지 않음.
- 학생 화면에 `진단완료 · 훈련 10문항 자동선정 완료` 표시.
- 관리자 수동 `훈련 10문항` 버튼은 제거하고 자동선정 안내로 변경.
- 관리자 진단·훈련 생성 이력에서 DRAFT/ASSIGNED 세션에 `생성 취소` 버튼 추가.
- 학생이 시작한 IN_PROGRESS 이상 상태는 취소 불가.

추가 SQL 없음. SOS208 DB 그대로 사용.
