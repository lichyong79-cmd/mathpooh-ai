# SOS132 LANDMARK SIMCITY

- 대한민국 3D 스타일 국토 실루엣 전면 재구성
- 서울: 63빌딩(대수), 롯데월드타워(미적분1)를 실제 서울권처럼 인접 배치
- 롯데월드타워는 원근상 살짝 뒤쪽/작게 배치
- 부산 해운대: LCT(확률과통계) 배치
- 과목별 실전모의고사 최고 점수를 랜드마크 완성도로 반영
- 최근 3회 실모 평균으로 맑음/흐림/비 도시 컨디션 결정
- 비는 Canvas 개별 빗방울과 바닥 파문으로 구현
- 공사 진행도에 따라 골조/크레인 영역이 줄고 완성 외벽이 올라오는 구조

참고: 백분위 필드가 현재 API 데이터에 없어 v1에서는 과목별 최고 점수를 0~100 완성도로 사용합니다.
