# SOS355 실전모의고사 시작 대기 흐름

1. 시험 시작 5분 전(예: 10:55)부터 `시험 보러가기` 버튼이 열립니다.
2. 학생은 시험 대기실로 이동하며 `관리자 시작 대기 중`을 확인합니다.
3. 관리자가 `시험 시작`을 누르면 대기 중인 학생에게 응시 동의서가 자동으로 나타납니다.
4. 학생이 동의하면 바로 시험 화면과 답안 입력 화면이 열립니다.

## 관리자 안전장치

- 시험 진행 중에는 `시험 시작` 버튼이 `시험 진행 중`으로 바뀌고 완전히 비활성화됩니다.
- 화면뿐 아니라 API에서도 이미 시작된 시험을 다시 시작할 수 없도록 막습니다.
- 기존 시험지 받기(시작 1시간 전 공개) 규칙은 유지합니다.
