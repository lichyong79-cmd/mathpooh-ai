# SOS43 빠른 자르기 + 자동분석 + 검토보류

## 변경사항
- 전체 분석을 `빠른 자르기`와 `문항별 분석`으로 분리
- 빠른 자르기 완료 후 전 문항 좌표를 즉시 표시
- `전체 한번에 보기` 추가
- `검토대상` 보기 추가
- 문항별 이미지를 자동 생성한 뒤 순차 AI 분석
- 자동 판정 기준 통과 문항은 `AUTO_REGISTERED`
- 기준 미달 문항은 `REVIEW`와 검토사유로 보류
- 수동 보정 단축 버튼 추가
  - 위 공백 줄이기
  - 아래 공백 줄이기
  - 왼쪽 줄이기
  - 오른쪽 줄이기

## 사용 순서
1. 시험지 선택
2. `빠른 자르기 시작`
3. `전체 한번에 보기`로 대략 확인
4. `자르기 저장 + 문항분석 자동 실행`
5. 완료 후 `검토대상`만 처리

## 자동등록 조건
- AI 신뢰도 86% 이상
- 정답 존재
- 단원/세부유형 존재
- 문항유형이 unknown이 아님

## 참고
현재 자동 처리 큐는 브라우저 화면이 열린 동안 순차 실행됩니다. 브라우저를 닫아도 계속되는 서버 백그라운드 큐는 다음 단계에서 별도 작업 큐로 분리해야 합니다.
