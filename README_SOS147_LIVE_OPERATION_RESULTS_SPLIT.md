# SOS 147 · 실전 운영/성적 분석 분리

## 학생 화면
- 시험 시작 동의 후 관리자가 아직 시작하지 않았으면 시험 대기실 표시
- 대기실은 2초마다 시험 상태를 확인하며 관리자 시작 즉시 자동 입장(F5 불필요)
- 응시 중 화면 이탈/복귀 및 창 포커스 이탈/복귀 로그 기록
- 해설 비공개 시 흐린 `해설지 보기` 버튼과 `관리자가 아직 해설을 공개하지 않았습니다.` 안내
- 미응답 행과 배지를 주황색 경고 상태로 변경

## 관리자 · 실전모의고사 진행
- 시험 시작/일시정지/재개/강제종료
- 학생별 응시상태, 시작/저장/제출 시각, 입력 답안 수
- 웹 응시 로그 표시

## 관리자 · 시험성적 분석
- 실전모의고사 진행 화면과 분리
- 총점
- 대수 / 미적분1 / 확통 영역별 정답 수
- 오답 문항 번호
- 매쓰푸의 코멘트 입력/저장
- 전체 및 학생별 해설 공개/비공개
- 하단의 작은 `문항별 정답률` 펼침 버튼
