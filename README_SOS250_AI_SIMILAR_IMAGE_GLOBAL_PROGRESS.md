# SOS250 — AI 유사문항 이미지 + 전체 처리 진행률

## 1. AI 유사문항 이미지 출력
- 2차 AI 유사훈련과 AI 유사문항 3제 굳히기를 학생 화면에서 텍스트 div가 아닌 SVG 시험지 이미지로 표시합니다.
- AI가 만든 문제의 question만 이미지화하며 정답/solution은 이미지에 포함하지 않습니다.
- 기존 문제은행 문항 이미지는 기존 방식 그대로 유지합니다.
- 관리자 SOS 결과/진행 상세에서도 같은 이미지로 확인합니다.
- 별도 Storage/SQL 없이 API 응답 시 안전한 SVG data URL을 생성합니다.

## 2. 공통 진행률 강화
- MATHPOOHLoader에 모든 장시간 작업의 실시간 경과시간을 추가했습니다.
- current/total이 있는 작업은 퍼센트와 예상 남은시간을 자동 계산합니다.
- AI 분석/전체 자르기/빠진 문항 채우기/문제은행 대량 등록은 처리량을 표시합니다.
- 문제은행 대량 등록은 20문항 단위로 나눠 실제 진행 정도가 움직이도록 변경했습니다.
- 서버 단일 요청처럼 사전에 전체량을 알 수 없는 작업은 허위 퍼센트를 만들지 않고 '전체량 확인/처리 중' + 경과시간을 표시합니다.

SQL 없음. SOS249 신규 난이도 통일 정책은 그대로 유지합니다.
