# SOS256 — SOS 진단 정오답+시간 판정 / 문항번호 자동 제거

- 문항번호: 고정 흰박스/SOS 로고 overlay 폐기. 이미지 상단의 첫 번호 토큰 뒤 공백을 감지해 번호까지만 자동 crop.
- 번호 탐지 실패 시에도 번호를 그대로 노출하지 않고 좌측 crop fallback.
- 진단: 같은 회차의 1·2차 진단을 누적해 오답과 풀이시간을 함께 판정.
- 오답은 무조건 취약 신호. 정답이어도 난이도별 예상시간의 1.35배 초과는 시간취약, 1.8배 초과는 심각 시간취약.
- 2차까지 끝난 뒤 오답 또는 시간취약이 하나라도 있으면 가장 강한 문항 DNA를 기준으로 1차 맞춤훈련 10문항 자동 생성.
- 1·2차 전체가 오답 0 + 시간취약 0일 때만 진단 종료.
- SQL 없음.
