# SOS242 — 운영 회차 통합

## 핵심 변경
- SOS241의 달력 `주차` 개념을 운영 기준에서 제거하고, 관리자가 직접 만드는 `회차`를 최상위 단위로 사용합니다.
- `회차 관리`에서 회차명(0회차/1회차/ㄱ회차 등), 시작일, 종료일을 직접 지정합니다.
- 실전모의고사를 회차에 배치합니다. 이미 응시/채점이 끝난 모의고사도 배치 가능하며 기존 점수·답안·분석은 변경하지 않습니다.
- 시험 하나는 한 회차에 속하도록 했고, 다른 회차로 이동할 때 확인창을 거칩니다.
- SOS 배정에서는 먼저 회차를 선택하고, 해당 회차에 배치된 실전모의고사 중 그 학생이 실제 응시한 시험의 오답만 기준시험/SOS_NO1 후보로 사용합니다.
- 진단 생성 시 `learningCycleId/name/start/end`를 `target_snapshot`에 기록합니다. 이후 1차훈련, 2차진단/훈련, 오답, AI 3제 굳히기는 기존 부모 snapshot 상속 구조를 통해 같은 회차를 자동 상속합니다.
- 관리자 배정 학생 목록에 선택 회차 기준 `SOS 미배정 / 진단 / 1차훈련 / 2차훈련 / 3제 굳히기 / SOS 완료 / SOS 없음` 상태를 표시합니다.
- 관리자 진행/결과/학습현황에서 회차 필터와 회차명을 표시합니다.
- 기존 과거 SOS는 `회차 미지정`으로 보존되며 `SOS 학습현황`에서 관리자가 회차를 지정하면 해당 SOS의 모든 하위 단계가 함께 이동합니다.
- 학생 나의 SOS에서도 회차 선택기로 현재/과거 회차를 조회하고, 기간이 지난 미완료 회차는 `밀린 SOS`로 이어서 학습할 수 있습니다.

## 배포 전에 반드시 1회 실행
Supabase SQL Editor에서 다음 파일을 실행합니다.

`supabase-v3.6-learning-cycles.sql`

새 테이블:
- `learning_cycles`
- `learning_cycle_exams`

기존 `exams`, `exam_attempts`, `sos_training_sessions` 데이터는 삭제/변경하지 않습니다.

## 첫 운영 순서
1. 관리자 → 실전모의고사 관리 → `회차 관리`
2. `회차명 + 시작일 + 종료일` 생성
3. 아래 `기존 실전모의고사 배치`에서 이번 회차 시험 선택
   - 이미 응시 완료된 시험도 그대로 선택 가능
4. SOS 학습운영 → 배정
5. 회차 선택
6. 학생 목록에서 `SOS 미배정` 학생 확인
7. 기준시험/SOS_NO1 확인 후 진단 3문항 배정
8. 이후 학생 학습은 같은 회차로 자동 귀속

## 검증
- TypeScript parser 기준 신규 수정 파일 구문 오류 없음.
- 프로젝트 node_modules가 ZIP에 포함되지 않아 이 작업환경에서는 Next.js 전체 build는 실행하지 않았습니다.
