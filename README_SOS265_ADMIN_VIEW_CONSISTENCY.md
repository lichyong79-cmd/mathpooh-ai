# SOS265 · 학습현황/진행/결과 일치 + 회차별 정리

- 관리자 GET 조회 중 중복 미응시 세션을 DB에서 삭제하던 부작용 제거. 조회는 읽기 전용으로 변경.
- 학습현황 API도 학생/세션을 전체 페이지 조회하고 진행 API와 같은 중복 미응시 제외 규칙을 사용.
- 진행/결과 화면을 회차별 구역으로 묶어 표시.
- 결과 화면 기본값을 `전체결과`로 변경해 완료된 진단/훈련/3제 결과가 한 화면에서 모두 보이도록 변경.
- 학습현황의 단계 클릭 시 진행 화면에서 해당 세션을 자동으로 열도록 연결.
- 신규 SQL 없음.
