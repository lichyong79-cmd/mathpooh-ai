# SOS V1 실전모의고사 통합 데모

구현 범위
- 관리자: 시험 목록, PDF 등록, 문항 영역 좌표 지정, 객관식/단답형 정답·배점 입력, 임시저장/배포
- 학생: 배포 시험 선택, 타이머, 답안 입력, 제출
- 자동 채점: 점수, 오답번호, 응시 결과 저장
- SOS 분석: 공략문항 → 진단3 → AI 판단 → 훈련10 흐름
- 브라우저 localStorage 데모 저장

## 실행
```bash
npm install
npm run dev
```

## 중요
현재 V1은 화면과 전체 흐름을 빠르게 검증하기 위한 로컬 데모입니다.
PDF 파일 자체와 잘라낸 문항 이미지는 아직 Supabase Storage에 영구 저장되지 않습니다.
문항 영역은 페이지별 백분율 좌표로 저장되며, 다음 단계에서 PDF.js 렌더링/이미지 크롭 및 Supabase 테이블·Storage에 연결하면 됩니다.
