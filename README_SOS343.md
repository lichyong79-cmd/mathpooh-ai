# SOS343 빠른정답 오독 및 객관식·주관식 입력 수정

## 수정 내용

- `객관식 문항 수`를 `객관식 마지막 번호`로 명확하게 변경했습니다.
- 객관식 마지막 번호를 바꾸면 이후 문항이 주관식으로 자동 전환됩니다.
- 각 정답 칸에 `객관식/주관식` 유형 버튼을 추가했습니다.
- 예를 들어 16번의 `객관식` 버튼을 눌러 주관식으로 바꾸면 1~15번 객관식, 16번 이후 주관식으로 즉시 변경됩니다.
- 저장 시 해설지 OCR을 자동 실행하던 동작을 제거했습니다.
- 관리자가 `마지막 빠른정답 읽기`를 눌렀을 때만 AI 인식값이 입력됩니다.
- 답 또는 문항유형을 수정하면 `정답 검수완료` 상태가 자동 해제됩니다.
- `인식값 전체 초기화` 버튼을 추가했습니다.

## OCR 안전성 개선

- 페이지 전체 숫자를 순서대로 짝짓던 위험한 보조 인식을 제거했습니다.
- 같은 줄에서 문항번호와 정답의 쌍이 확인된 경우만 입력합니다.
- 애매한 값은 잘못 채우지 않고 빈칸으로 남겨 수동 확인하도록 했습니다.

## 적용

- 별도 SQL 없이 코드만 배포하면 됩니다.
- SOS340R~342 변경사항도 모두 포함되어 있습니다.

## 시험 파일 저장 오류 수정

- 시험 저장 중 기존 파일 주소를 먼저 조회하던 동작을 제거했습니다.
- 비공개 시험 파일 열기는 관리자 인증을 확인한 서버에서 처리합니다.
- 실패 이력의 파일명만 있고 실제 파일이 없는 경우 전체 시험을 다시 만들 필요 없이, 없는 파일만 `파일 변경`에서 다시 선택하면 됩니다.
