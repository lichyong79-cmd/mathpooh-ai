# SOS211 - 성적 동기화 + 진단 후보 10문항

## 변경
- 학생 페이지가 관리자 성적 변경을 자동 반영하도록 5초 주기/포커스 복귀 시 portal 재조회
- SOS_NO1 확정 시 더 이상 진단 3문항을 즉시 자동 배정하지 않음
- 문제은행 ACTIVE/TRAINING 문항을 대상으로 타겟 문항과의 소단원/DNA/과목/난이도 연관도를 계산해 최대 10개 후보 표시
- 후보마다 문항 이미지, 소단원, 난이도, 문항 미터, 연관도, 핵심 DNA 태그 표시
- 관리자가 정확히 3문항을 선택한 뒤 `선택한 3문항 진단 확정`을 눌러야 학생에게 배정
- 같은 소단원 문항이 부족해도 후보 화면 자체가 막히지 않도록 전체 훈련문항에서 연관도 순으로 최대 10개 제공

## 이번 버전에서 유지
- 학생 진단 10초 준비/풀이시간/답안확정/사진제출시간/이탈로그 흐름은 SOS210 그대로 유지
- 훈련 이후 오답/재훈련/완성 판단은 아직 미구현 범위
