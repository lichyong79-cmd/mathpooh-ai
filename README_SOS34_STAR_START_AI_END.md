# SOS34 — ★ 시작점 + AI 끝점 자르기

## 변경 방식

- 시험지 PDF의 `★` 문자를 PDF 텍스트 좌표로 직접 탐지합니다.
- `★`가 없는 예제·설명은 문항 시작점으로 등록하지 않습니다.
- 문항 시작 좌표와 좌/우 단의 가로 범위는 프로그램이 고정합니다.
- AI는 각 문항의 실제 마지막 내용 아래 `bottom_y`만 판단합니다.
- 다음 ★까지 통째로 자르지 않습니다.
- 해설지 PDF는 기존처럼 시험지와 함께 AI 문항 분석 및 정답 확인에 사용합니다.

## 한글 원본 작성 규칙

- 실제 등록할 문항번호 바로 앞에 검은 별 `★`를 넣습니다.
- 예제나 참고문제에는 별을 넣지 않습니다.
- 별은 그림이 아니라 문자로 입력하고 PDF로 저장해야 합니다.

## 실패 메시지

PDF 텍스트에 `★`가 남아 있지 않으면 분석을 중단하고 별표를 찾지 못했다는 메시지를 표시합니다.
