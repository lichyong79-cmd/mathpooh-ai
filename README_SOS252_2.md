# SOS252.2

## 1차훈련 통과 규칙 수정
- 1차훈련은 다음 중 하나를 만족하면 통과:
  1. 바로미터가 목표 이상
  2. 최초 채점 9/10 이상(90% 이상)
- 9/10 통과 후 오답 교정을 완료하면 2차 AI 유사훈련 10문항을 만들지 않고 `3제 굳히기` 3문항 생성.
- 90% 미만이면서 바로미터 목표도 미달일 때만 2차 AI 유사훈련 10문항 생성.
- UI에 9/10 통과와 바로미터 목표 달성을 구분해 표시.

## 문제 이미지 번호 마스킹
- 기존의 큰 고정 흰 박스를 제거.
- SOS 로고와 원본 문항번호 마스킹을 분리.
- 번호 영역만 비율 좌표로 가리고 문제 첫 글자를 침범하지 않도록 수정.
