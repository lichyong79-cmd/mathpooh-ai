# SOS289 · 문제은행 검색 근본 수정

문제은행 검색이 실제 운영에서 잘 안 잡히던 부분을 수정했습니다.

## 원인
1. 검색 대상에 `question_no`가 직접 포함되지 않았고, 일부 문항은 제목에 번호가 없어 번호 검색이 불안정했습니다.
2. 검색 문자열을 SQL LIKE용 보정 함수처럼 가공하면서 괄호/쉼표 등 구두점이 섞인 시험지명·DNA 검색이 쉽게 끊겼습니다.
3. 검색 결과가 바뀌어도 우측 상세 화면은 기존 `selectedId`를 그대로 유지했습니다. 목록은 필터됐는데 상세는 이전 문항을 보여 검색이 안 된 것처럼 보일 수 있었습니다.
4. 난이도 관리 화면도 별도의 단순 `includes()` 검색을 사용해 같은 계열의 문제가 있었습니다.

## 수정
- Unicode NFKC + 소문자 + 구두점/공백 정규화 기반 검색
- 여러 단어 입력 시 각 토큰이 모두 포함되면 검색되도록 개선
- 문항번호 / `75번` / 시험지명 / 코드 / 과목 / 단원 / 유형 / 요약 / 정답 / 출처 / 난이도 / DNA / 내부 ID까지 검색 대상 확대
- 검색 결과에서 기존 선택 문항이 빠지면 첫 검색결과를 자동 선택하여 목록과 상세 동기화
- `문제은행`과 `난이도 관리` 검색을 같은 방식으로 보강

## 테스트 예시
- `75`
- `75번`
- `EBS 수능특강`
- `등차수열 항과 합`
- 문제 문구/DNA 핵심어 일부
