# SOS336 - 학생·회차 등록과 시험지 배정 분리

- 학부모 신청 → 관리자 결제 확인 → 학생과 선택 회차를 먼저 연결
- 회차와 시험지는 별도 운영 흐름으로 연결
- 결제 확인과 시험지 연결 중 어느 작업을 먼저 해도 최종 시험 배정 자동 동기화
- 신청 취소/삭제 시 미응시 시험 등록만 해제
- 이미 응시한 시험, 성적, SOS 학습 기록과 원본 회차·시험지는 유지
- 회차에서 시험지를 빼면 해당 회차의 미응시 자동배정만 해제
