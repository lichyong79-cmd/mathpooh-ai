# SOS335 - 관리자 신청 취소·삭제 및 모집안 삭제 수정

## 수정 내용
- `등록 완료`, `결제 확인`, `신청 접수` 상태 모두 관리자 취소 가능
- 취소 시 SOS 등록 상태도 `CANCELLED`로 함께 변경
- 모든 신청 행에 `신청 삭제` 버튼 추가
- 신청 삭제는 신청서와 연결된 SOS 등록행만 정리
- 기존 회차, 시험 응시, 성적, SOS 학습 기록은 삭제하지 않음
- 진행 중 신청이 없는 모집안은 취소/환불 신청을 정리한 뒤 삭제 가능
- 진행 중 신청이 남아 있으면 정확한 건수와 먼저 처리할 순서를 안내
