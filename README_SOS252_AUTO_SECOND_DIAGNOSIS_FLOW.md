# SOS252 — 1차 진단 만점 자동 2차 진단

핵심 흐름
1. 관리자가 최초 SOS 핵심공략 1개와 진단 3문항만 최초 배정.
2. 최초 배정 시 다음 추천 핵심공략 후보 최대 5개를 target_snapshot.autoNextTargets에 함께 저장.
3. 학생이 1차 진단 3/3 정답이면 오답/결과 확인 단계에서 멈추지 않음.
4. 서버가 즉시 다음 추천 핵심공략을 자동 선택.
5. 문제은행에서 해당 핵심공략과 DNA/소단원이 맞는 진단문항을 학생 미터 기준 쉬움-적정-도전 3문항으로 자동 선정.
6. 2차 진단 세션 ASSIGNED 생성 후 학생 화면이 자동 이동.
7. 이전 세션처럼 autoNextTargets가 없는 데이터는 '현재 소단원 제외, 학생 바로미터 최저 다른 영역'으로 자동 fallback.
8. 중복 2차 진단 세션 생성 방지.

관리자 개입
- 최초 SOS 핵심공략/1차 진단만 관리자 선택.
- 1차 진단 만점 이후 2차 진단 생성에는 관리자 개입 0.

SOS250 이미지 유사문항/전체 진행률, SOS249 신규 난이도 통일 등 기존 기능 유지.
