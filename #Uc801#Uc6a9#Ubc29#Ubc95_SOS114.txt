SOS114 학생 화면 4개 영역 분리

적용 내용
- SOS 신청하기: 관리자 등록 포스터 및 프로그램 안내
- 실전모의고사: 신청·배정 시험, 시험지 다운로드, 응시 및 결과 확인
- SOS 공략: 진단/훈련 연결 상태와 향후 3+3 진단, 10문항 훈련 영역
- 학습분석: 응시 횟수, 평균 점수, 최근 성적 및 시험별 결과 상세
- PC: 상단 고정 메뉴
- 모바일: 햄버거 메뉴

적용 방법
1. ZIP 압축을 프로젝트에 덮어씁니다.
2. npm install
3. npm run build
4. git add .
5. git commit -m "SOS114 학생 화면 4개 영역 분리"
6. git push

SQL
- SOS113에서 supabase-v3.0-site-posters.sql을 이미 실행했다면 추가 SQL은 없습니다.
- 아직 실행하지 않았다면 해당 SQL 파일을 Supabase SQL Editor에서 한 번 실행하세요.
