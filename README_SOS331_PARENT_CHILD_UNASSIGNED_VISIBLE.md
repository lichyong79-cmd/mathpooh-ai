# SOS331 - 학부모 자녀 배정 전 표시

기준: SOS330

## 변경
- 학부모에게 연결되거나 새로 생성된 학생은 시험 배정 여부와 관계없이 자녀 목록에 표시됩니다.
- `exam_registrations`의 실제 상태를 기준으로 자녀 상태를 계산합니다.
  - 등록 없음: `배정 전`
  - 신청만 완료: `신청 접수`
  - 시험 배정 완료: `배정 완료`
- 자녀가 1명일 때 우측 상태 배지를 `배정 전 / 신청 접수 / 배정 완료`로 표시합니다.
- 자녀가 여러 명일 때 선택 목록에도 각 자녀의 배정 상태를 함께 표시합니다.
- 홈 상단 상태도 미배정 학생이면 `배정 전`으로 표시합니다.

## 변경하지 않은 영역
- 학생 생성/기존 학생 연결 규칙
- 시험 배정 로직
- SOS 학습 엔진
- AI 생성
- 문항 인식/자르기 엔진
