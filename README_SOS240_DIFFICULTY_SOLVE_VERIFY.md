# SOS240 — 난이도 재풀이 검증 엔진

## 목적
기존 난이도 분포에서 3점 쏠림이 의심되는 문제를 해결한다. AI가 애매하거나 실패했을 때 3점으로 보내지 않고 `미분류/검토필요`로 분리한다.

## 핵심 변경
1. **3점 fallback 제거**
   - 문제은행/난이도 관리 UI에서 정상화 실패를 더 이상 3점으로 표시하지 않는다.
   - `difficulty_decision=unclassified` 문항은 기존 숫자가 DB에 남아 있어도 화면상 `미분류`로 보인다.

2. **2단계 난이도 판정**
   - 1차: 첨부 문제 이미지를 AI가 처음부터 독립 재풀이한다.
   - 2차: 재풀이 결과 + 공식 정답 + Problem DNA + 관리자 확정 기준문항을 대조해 8단계 난이도를 판정한다.
   - 재풀이 검증 실패, 공식답 불일치, 신뢰도 부족 시 `unclassified` 처리한다.

3. **표본 검증 우선**
   - 난이도 관리 화면의 `① 표본 재풀이 검증`은 DB 난이도를 변경하지 않는다.
   - 8단계별 표본 + 과밀한 기존 3점 문항을 추가 샘플링한다.
   - 기존→신규 이동, 미판정, 검토필요, 독립 재풀이 산출답과 추론부담을 화면에 표시한다.

4. **전체 재판정 안전 적용**
   - 표본 실행 후에만 `② 검증 엔진 전체 재판정` 버튼이 활성화된다.
   - 관리자 확정 문항은 보존한다.
   - `graded + review_required=false`인 검증 통과 문항만 실제 difficulty를 갱신한다.
   - 미판정/검토필요 문항은 기존 난이도를 덮어쓰지 않고 검토 메타데이터만 저장한다.

5. **대시보드 가시성**
   - 문제은행 난이도 분포에 `미분류`를 9번째 항목으로 표시한다.
   - 난이도 관리 KPI에 `미분류 / 검토필요 / 구버전·미검증`을 별도로 표시한다.

## DB
신규 SQL/컬럼 없음. `problem_dna.difficulty` JSON 내부에 검증 메타데이터를 기록한다.

## 운영 순서
1. 배포 후 `관리자 > 난이도 관리` 진입
2. `① 표본 재풀이 검증` 실행
3. 기존→신규 이동과 미판정/검토필요 비율 확인
4. 결과가 납득되면 `② 검증 엔진 전체 재판정` 실행
