# SOS 146 · 첫 실전시험 반영

## 적용
- SOS 학습관리 → SOS 학습운영
- 정답 수정 저장 시 제출 완료자 자동 전체 재채점
- 수동 점수는 유지하고 정오/취약 분석만 최신 정답으로 갱신
- 학생 누적 성취도 정답 수를 최신 정답 기준으로 계산
- SOS LANDMARK를 혼합 시험의 문항별 과목/단원 기준으로 분배
- 전체/학생별 해설 공개용 DB 필드 및 API
- 매쓰푸의 코멘트 저장 필드 및 결과 상세 입력창

## 배포 전 SQL
`supabase-v2.7-result-controls.sql`을 Supabase SQL Editor에서 1회 실행하세요.

## 주의
SOS LANDMARK는 문항 분석의 단원명에서 대수/미적분1/확률과통계를 판별합니다. 분석 정보가 없는 문항은 시험 과목명을 보조값으로 사용합니다.
