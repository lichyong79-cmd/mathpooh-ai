# SOS344 수능형 객관식·주관식 및 빠른정답 수정

## 정확한 문항 유형

- 1~15번 객관식
- 16~22번 주관식
- 23~28번 객관식
- 29~30번 주관식
- 관리자 정답 입력, 학생 OMR, 시험지 문항영역에 동일 규칙을 적용했습니다.
- 이전 오류로 30문항 시험이 객관식 29개로 저장됐어도 편집 화면을 다시 열면 21개/9개로 정상화됩니다.

## 빠른정답 인식

- 주관식 16번 `28`, 19번 `8`, 20번 `136`, 21번 `324`, 22번 `13`, 29번 `539`가 객관식 범위 검사에서 탈락하던 문제를 수정했습니다.
- 제공된 빠른정답 표의 30개 답을 문항번호와 정확히 연결할 수 있도록 유형 검사를 수정했습니다.

## 포함 사항

- SOS343 시험 저장 `Object not found` 수정 포함
- TypeScript 검사 통과
