# SOS254 — 회차 전체 단계 기준 자동복구

문제
- SOS253 자동복구가 parent_session_id 중심으로만 다음 단계 존재 여부를 판단.
- 과거 생성된 세션 중 parent 연결이 약하거나 누락된 경우, 완료된 1차훈련이 있는데도 새 1차훈련을 다시 생성할 수 있었음.
- 9/10 완료 학생이 3제 굳히기 대신 또 1차훈련으로 보이는 현상 발생.

수정
- `ensure_next`는 같은 학생 + 같은 회차의 전체 세션을 먼저 조회.
- 같은 회차에 1차훈련이 이미 있으면 진단 단계에서 새 1차훈련 절대 생성 금지.
- 기존 1차훈련이 완료됐으면 그 세션의 점수/바로미터를 기준으로:
  - 9/10 이상 또는 목표달성 → HOMEWORK 3문항
  - 그 외 → 2차훈련 10문항
- HOMEWORK/2차훈련이 이미 있으면 절대 재생성하지 않고 기존 세션 반환.
- 학생 화면도 부모-자식 링크가 아니라 같은 회차의 실제 단계 존재 여부를 기준으로 CTA/자동복구 판단.
- 이미 완료된 1차훈련이 있는 상태에서 뒤늦게 잘못 생성된 중복 1차훈련은 '지금 해야 할 SOS'로 표시하지 않음.
