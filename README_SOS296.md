# SOS296 · 실패 문항만 격리 재생성

## 확인된 원인

- 최종 재풀이가 출제 답의 수학적 오류를 올바르게 검출하고 있었습니다.
- 조판 검수도 수식 구분자 불일치를 올바르게 검출하고 있었습니다.
- 문제는 3문항 묶음 중 한 문항만 실패해도 묶음 전체를 버려, 이미 정상 생성된 문항도 사라지는 구조였습니다.

## 변경

- 3문항 묶음 검증 실패 시 문항별 격리 생성으로 자동 전환합니다.
- 개별 검증을 통과한 문항은 즉시 `batch_payload`에 보존합니다.
- 다음 실행은 보존된 다음 번호부터 이어서 생성합니다.
- 내부 생성/재검증을 2회에서 3회로 늘렸습니다.
- 텍스트 출제 추론 강도를 `low`에서 `medium`으로 높였습니다.
- 관리자 카드에 `n문항 보존`과 작업 식별번호를 표시합니다.
- 실패 버튼 문구를 `실패 문항만 이어서 생성`으로 변경했습니다.

## SQL

추가 SQL은 없습니다. SOS290의 `batch_payload` 컬럼이 이미 적용되어 있어야 합니다.

## 배포 후

현재 FAILED 카드에서 `실패 문항만 이어서 생성`을 한 번 누릅니다. 보존 문항이 있으면 그 다음 문항부터 이어집니다.
