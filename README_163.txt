SOS 163 · 시험지/해설 PDF 부분 갱신

적용:
- 이 ZIP의 src 폴더를 프로젝트 루트에 그대로 덮어쓰기
- 추가 SQL 없음

동작:
1) 관리자 > 문제등록 > 기존 시험지 수정
2) 문제 PDF 또는 해설 PDF 교체
3) 교체 직후 다시 가져올 문항 번호 선택
4) 문제 PDF: [이미지만 교체] 또는 [이미지 + AI 분석 갱신]
5) 해설 PDF: 선택한 해설 이미지만 갱신

안전장치:
- 문항 ID 유지
- 이미지 전용 교체 시 정답/단원/유형/DNA 유지
- AI 분석 갱신 시 선택 문항만 재분석 후 problem_bank_questions에 upsert
- 문제은행 상세의 기존 '이 문항만 교체' 버튼 제거
