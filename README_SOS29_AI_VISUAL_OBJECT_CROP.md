# SOS29 AI 문항 객체 크롭

변경 범위는 문항 크롭 엔진입니다.

## 변경 내용

1. 최초 크롭 프롬프트를 문항번호 간격 방식이 아닌 문항 객체 인식 방식으로 교체
2. 문항번호·본문·수식·조건·보기·선택지·표·그래프·도형을 하나의 문항으로 묶어 최소 사각형 생성
3. 최초 크롭 이미지를 전체 시험지 PDF와 다시 비교하는 AI 품질 검수 API 추가
4. 누락·다른 문항 혼입·과도한 공백이 발견되면 절대 좌표를 수정하고 이미지 자동 재생성
5. 검수가 끝난 이미지에 대해서만 문항 분석 실행

## 새 API

- `POST /api/analysis/questions/[id]/review-crop`

## 실행 순서

PDF → AI 문항 객체 검출 → 이미지 생성 → AI 크롭 검수 → 필요 시 좌표 수정 및 재생성 → 문항 분석

## 확인

수정한 TypeScript/TSX 3개 파일은 TypeScript 구문 변환 검사 통과.
현재 작업 환경에는 프로젝트 의존성(`node_modules`)이 없어 `next build`는 실행하지 못함.
