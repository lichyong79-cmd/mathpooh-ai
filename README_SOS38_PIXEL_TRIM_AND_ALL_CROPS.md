# SOS38 · AI 크롭 픽셀 여백 정리 + 전체 잘린 결과 복원

## 적용 내용
- 기존 한 문항별 드래그/저장 검수 화면 유지
- `전체 잘린 결과` 화면 복원
- 전체 썸네일 클릭 시 해당 문항 단일 검수 화면으로 이동
- AI bounding box 안의 실제 픽셀 분포를 조사해 상하좌우 흰 여백 자동 정리
- 수식, 도형, 보기 상자, 컬러 인쇄를 보존하도록 밝기/채도 기반 내용 픽셀 판정
- 분수·지수·선택지가 잘리지 않도록 상하좌우 안전 여백 유지
- AI 검수 권장 문항은 전체보기에서 주황색으로 표시
- 단일 화면에 `흰 여백 자동 정리` 버튼 추가

## 수정 파일
- `src/app/problem-bank/crop/page.tsx`

## 테스트 순서
1. 기존 시험지 완전 삭제
2. 시험지 재등록 및 AI 분석
3. 문항 영역 검수 진입
4. `전체 잘린 결과` 선택
5. 이상한 문항 클릭 후 단일 화면에서 드래그 수정/저장
