# SOS329 · 유료 운영 추가 안전장치

SOS328의 유료 운영 안정화에 다음을 추가했다.

1. 5회 묶음 생성 시 관리자가 회차를 클릭한 순서가 아니라 실제 `start_date` 순으로 1~5회차를 자동 정렬한다.
2. 이미 시작한 회차가 포함된 묶음은 새로 만들 수 없다.
3. 신청 열기(publish) 시 정확히 5회 연결, 시작일 존재, 1회차 미경과, 신청기간 역전 여부를 서버에서 재검증한다.
4. 관리자 화면의 '신청 n명'은 취소/환불을 제외한 REQUESTED/PAID/ENROLLED만 집계한다.
5. 관리자 신청 내역에 학생 전화번호도 같이 표시한다.
6. 기존 개별 시험 신청 기능에서도 시험일이 이미 지난 시험은 서버가 새 신청을 거절한다. `student_open=true`가 실수로 남아 있어도 과거 시험 신청이 생기지 않는다.

주의: SOS323 이후 동결한 자르기 엔진은 수정하지 않았다.
