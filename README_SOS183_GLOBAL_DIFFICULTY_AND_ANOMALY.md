# SOS183 - 8단계 난이도 전 시스템 공통화 + AI 이상 난이도 검토

- 공식 난이도: 2점 / 3점 / 어3 / 쉬4 / 적4 / 어4 / 준킬러 / 킬러
- 실전모의고사 AI 분석도 공용 난이도 가이드 사용
- 결과/성적분석/학생 화면은 공용 difficultyLabel 및 공용 가중치 사용
- 난이도 관리의 일상 기능을 `AI 이상 난이도 검토`로 변경
  - 저장 AI 메타데이터의 불일치/낮은 신뢰도/극단값을 우선 선별
  - AI 2차 검토 후 현재값과 다른 문항만 표시
  - 자동 DB 변경 없음: 현재 유지 / AI 제안 적용 / 직접 수정
- SOS 학습운영 문제은행 숫자 1,000 제한 제거
  - ACTIVE 전체 문항수는 count: exact 사용
  - TRAINING 후보는 1,000개씩 페이지네이션해 전체 조회
