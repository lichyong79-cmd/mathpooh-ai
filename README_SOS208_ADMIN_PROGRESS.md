# SOS208 · 관리자 진단/훈련 진행현황

SOS207 누적본. 207 배포 후 그대로 208로 덮어쓰기 가능.

관리자 `SOS 학습운영` → `진단·훈련 진행현황`

확인 항목:
- 학생 / 학교 / 학년 / 반
- 진단 1차·2차... 또는 훈련
- 과목 / 대단원 / 소단원
- 미응시 / 진행중 / 완료 / 통과 / 재훈련
- 응답 진도 n/3 또는 n/10
- 완료 정답수와 정답률
- 배정시각 / 시작시각 / 제출시각 / 경과시간
- 해당 소단원 시작 미터 → 현재 미터 변화
- 15초 자동 새로고침
- 학생·학교·반·소단원 검색 및 진단/훈련/상태 필터

추가 SQL 없음. SOS207 DB 그대로 사용.
