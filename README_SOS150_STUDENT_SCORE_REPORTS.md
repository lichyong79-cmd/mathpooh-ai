# SOS150 · 학생성적 분석 — 시험별 성적표

## 반영 내용
- 관리자 `학생성적 분석`을 독립 페이지로 분리
- 학생 이름·학교 검색
- 학생 선택 시 응시 완료 시험을 최신순으로 표시
- 시험 선택 시 개인 성적표 표시
  - 총점, 정답·오답·미응답
  - 대수·미적분1·확률과통계 영역별 정답 수와 정답률
  - 오답·미응답 문항 번호
  - 문항별 정오 상태
  - 매쓰푸의 코멘트
  - 해설 공개 상태
- 성적표 인쇄 버튼
- 기존 `학생학습 분석`의 누적 성취도 페이지는 별도로 유지
