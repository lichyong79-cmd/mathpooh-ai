## 상황

SOS293으로 MathML 건은 통과했고, 이번엔 다른 사유입니다.

```
FAILED · 조판 검수 실패: 2번 displayLatex에 MathJax 수식 구분자가 없음,
                        3번 displayLatex에 MathJax 수식 구분자가 없음
```

## 원인 두 가지

### ① 검수 기준이 지나치게 넓었습니다

```ts
if(!/(\\\(|\\\[)/.test(latex)) return "MathJax 수식 구분자가 없음";
```

`\( \)` 나 `\[ \]` 가 **하나도 없으면 무조건 실패**시켰습니다.

그런데 수식 없이 문장과 숫자만으로 성립하는 문제도 있습니다.
예를 들어 "1부터 10까지의 자연수 중 3의 배수의 개수를 구하시오" 같은 문항은
구분자가 없는 게 정상인데도 탈락했고, 그 때문에 **묶음 3문항이 통째로** 다시 만들어졌습니다.

이제 **LaTeX 명령이 구분자 밖에 노출된 경우에만** 실패시킵니다.
그 경우는 화면에 `\frac` 같은 글자가 그대로 보이므로 실제 문제가 맞습니다.

### ② 조판 모델이 구분자를 자주 빠뜨립니다

3문항 중 2문항이 같은 사유였다는 건 우연이 아닙니다.
이건 다시 만들어도 반복될 가능성이 큽니다.

그래서 **실패시키는 대신 자동으로 감쌉니다.**

```ts
function wrapLooseLatex(raw) { ... }
```

문장 안의 LaTeX 조각(`\frac{1}{2}`, `x^2`, `a_{n+1}` 등)을 찾아
`\( ... \)` 로 감싸줍니다. 이미 구분자가 있는 문서는 건드리지 않습니다.

| 입력 | 출력 |
|---|---|
| `\frac{1}{2} 과 \sqrt{3} 의 곱` | `\(\frac{1}{2}\) 과 \(\sqrt{3}\) 의 곱` |
| `수열 a_{n+1} 의 값` | `수열 \(a_{n+1}\) 의 값` |
| `\( a_n \) 의 합` (이미 정상) | 그대로 |
| `3의 배수의 개수` (수식 없음) | 그대로 |

### ③ 프롬프트도 강화

> 모든 수식과 변수, 지수, 첨자는 예외 없이 `\( ... \)` 안에 넣습니다.
> `f(x)`, `x^2`, `a_n` 처럼 짧은 것도 반드시 감쌉니다.
> 구분자 밖에 LaTeX 명령을 두면 화면에 글자 그대로 노출됩니다.

| SOS294 | 수식 구분자 없음 | 정상 문항까지 탈락시킴 + 모델이 자주 빠뜨림 |

공통점은 **"안전장치가 지나치게 엄격해서 아무것도 통과하지 못한 것"** 입니다.
난이도 판정에서 겪은 것과 같은 구조였습니다.

이번 수정으로 **정말 문제가 되는 것만** 걸러냅니다.

- 정답이 정수가 아님 → 실패 (맞음)
- 재풀이 답이 다름 → 실패 (맞음, 학생에게 틀린 문제를 주지 않기 위함)
- 화면에 raw LaTeX 노출 → 자동 보정, 그래도 안 되면 실패
- 화면에 안 쓰이는 데이터 문제 → 정리하고 진행

**또 FAILED가 나오면 사유를 알려주세요.**
`재풀이 검증 실패`라면 그건 정당한 실패이므로 다시 누르시면 대개 통과합니다.
