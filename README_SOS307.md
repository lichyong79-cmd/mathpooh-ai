# SOS307 · 난이도 관리 목록에서 문제 보고 바꾸기

**파일 1개.** SQL 없음. SOS306 위에 덮어쓰세요. 빌드 확인 완료(47/47).

```
src\app\problem-bank\difficulty\page.tsx
```

---

## 문제

난이도 관리 화면 목록에는 **문항번호 · 코드 · 단원 · 출처 · 난이도 드롭다운**만 있습니다.
문제가 보이지 않으니 **난이도를 바꿀 판단을 할 수가 없습니다.**

문항 이미지는 `① 표본 재풀이 검증` 결과 카드에만 있었는데,
그건 무작위 48문항이라 원하는 문항을 찾아갈 수도 없었습니다.

## 고친 방법

**목록 행을 누르면 그 자리에서 문제가 펼쳐집니다.**

```
▸ 106번   dec2fbde-…   독립시행과 경우의 수 분류   EBS   [3점 ▾]
```

행을 클릭하면 `▾`로 바뀌면서 아래로 문항 이미지가 열립니다.
한 번 더 누르면 접힙니다.

오른쪽에는 판단에 필요한 정보를 함께 보여줍니다.

- 문항명 · 과목 · 단원 · 출처
- **AI 재풀이로 확정된 난이도인지, DNA 점수로 계산한 추정치인지**
- 관리자가 직접 바꾸면 확정으로 저장된다는 안내

난이도 드롭다운을 조작할 때는 펼침/접힘이 반응하지 않습니다.

## 관리자가 바꾼 난이도는 보호됩니다

목록에서 난이도를 바꾸면 `admin_fixed: true`가 함께 기록됩니다.
이후 **AI 재판정도, DNA 보조 계산도 그 값을 덮어쓰지 않습니다.**
사장님이 직접 확정한 것이 최종입니다.

## 이렇게 쓰시면 됩니다

**특정 등급을 점검할 때**

1. 난이도 드롭다운에서 `3점` 선택
2. 목록을 훑으며 의심스러운 행을 클릭
3. 문제를 보고 그 자리에서 난이도 변경

**AI 미검증 문항을 정리할 때**

1. 난이도 드롭다운에서 `AI 미검증` 선택
2. 같은 방식으로 하나씩 확인·확정

한 번 확정한 문항은 다시 대상이 되지 않으므로,
시간 날 때마다 조금씩 해두시면 쌓이지 않습니다.
