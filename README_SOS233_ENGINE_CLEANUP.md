# SOS233 ENGINE CLEANUP / PERFORMANCE PASS

기능 추가 없이 SOS232를 정리한 안정화 버전입니다.

- 훈련 제출 시 문항/중복 이벤트/학생 바로미터 조회 캐시로 DB 왕복 감소
- 관리자 진행 목록 API를 경량화하고 문항/사진/힌트/로그는 클릭 시 상세 조회
- 관리자 자동 갱신 15초 -> 30초
- 공통 SOS 상태/단계 라벨 헬퍼 `src/lib/sos-stage-state.ts` 추가
- 미사용 구형 `src/lib/sos-auto-training.ts` 제거
- 전역 대형 로더를 AI 분석/제출/리셋/시험지 생성 등 실제 장기 작업으로 제한
- 기존 진단/1차훈련/2차훈련/숙제/오답/리셋 규칙은 유지

## 리셋 안정성
현재 리셋 로직의 연쇄 정리 순서를 유지했습니다. 완전한 DB 트랜잭션은 Supabase SQL RPC가 필요하므로, UI 직전 안정화 버전에서는 기존 스키마를 깨지 않기 위해 RPC 강제 전환은 하지 않았습니다. 운영 전 별도 트랜잭션 RPC로 옮기는 것을 권장합니다.
