# SOS206 · 난이도 바로미터 검증 화면

SOS205 위에 검증 UI만 추가.

경로:
- 난이도 관리 → `학생·문항 바로미터`
- 직접 주소 `/problem-bank/barometer`

학생별 바로미터:
- 학생/학교/학년
- 과목 / 대단원 / 소단원
- 현재 내부 미터 1.00~8.00
- 현재 8단계 라벨
- 해당 소단원 누적 응답 표본수

문항별 바로미터:
- DNA 최초 난이도
- 현재 동적 미터
- 현재 8단계 라벨
- 서로 다른 학생 수 / 총 응답 수
- DNA 고정(20명 미만) / 실측 반영(20명 이상)
- 최초 대비 현재 미터 변화량

기능 로직은 변경하지 않고 검증/표시만 추가.
