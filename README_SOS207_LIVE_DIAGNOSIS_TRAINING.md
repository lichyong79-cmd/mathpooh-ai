# SOS207 · 실제 진단 3문항 + 훈련 10문항

SOS206 누적본.

흐름:
1. 관리자 SOS학습운영에서 실제 모의고사 오답을 SOS_NO1으로 확정.
2. 같은 과목 + 같은 소단원에서 학생 미터 기준 -0.9 / 현재 / +0.9 진단 3문항을 생성하고 즉시 ASSIGNED.
3. 학생 `나의 SOS 공략` 화면에서 진단 시작 → 3문항 답 입력 → 전체 제출.
4. 서버가 정답 자동채점하고 각 문항 순서대로 학생 소단원 미터를 업데이트.
5. 문항 미터는 서로 다른 학생 20명부터 실측 반영.
6. 관리자는 완료된 진단을 보고 훈련 10문항 생성.
7. 같은 소단원에서 안정화2 / 적정5 / 상향3 배정.
8. 학생이 훈련 10문항 제출 → 자동채점 → 미터 업데이트.
9. 훈련 80% 이상이면 PASSED, 미만이면 RETRAIN 판단.

중요:
- 진단 중에는 정답/오답을 바로 공개하지 않고 전체 제출 후 채점.
- 문제은행 answer를 정답 기준으로 사용.
- 학생/문항 바로미터는 SOS206 검증 화면에서 확인 가능.

DB:
- SOS205 SQL `supabase-v3.1-subunit-difficulty-link.sql` 실행 필수.
- 추가로 `supabase-v3.2-sos-live-diagnosis-training.sql` 실행.

소단원 기준은 Problem DNA `basic.minor_unit` 최우선, 없을 때 middle_unit → 기존 unit 순으로 fallback합니다.
