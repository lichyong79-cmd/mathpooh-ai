# SOS317 · 정상 인식·자르기 엔진 보존 + 누락 문항만 직접 추가

## 원칙

- 기존에 잘 작동하던 SOS312의 `question-anchors.ts`를 그대로 복원했습니다.
- 기존 문항의 인식 좌표·단 구분·문항 경계·자르기 계산은 수정하지 않았습니다.
- 전체 PDF 숫자를 자동 탐색해 기존 경계를 덮는 기능은 제거했습니다.

## 추가 기능

1. `＋ 누락 문항 직접 추가` 클릭
2. 추가할 문항번호 직접 입력
3. PDF에서 해당 문제 전체를 드래그
4. 해당 문항만 인식 목록에 추가
5. 이후 기존 2단계 자르기 엔진으로 처리

문항번호를 임의로 추측하지 않으며, 한 문항을 저장한 뒤 다음 문항번호 입력칸은 비웁니다.
따라서 좌측 단처럼 AI가 놓친 문항만 관리자가 정확히 보완할 수 있습니다.

## 포함 사항

- SOS314 문제인식 → 자르기 → 문항분석 실제 공정 분리
- SOS315 전체 프로그램 진행률 화면 통일

추가 SQL은 없습니다.
