# SOS249 — 신규문항 난이도 단일 기준 고정

핵심
- 기존 문항 `DNA만 재계산(보조)`와 신규문항이 동일한 `applyOperationalDifficultyPolicy()`를 사용합니다.
- AI 분석 직후: DNA 근거 + 수능 band를 결합한 8단계 난이도를 즉시 계산합니다.
- 문제은행 등록 직전: 같은 함수를 다시 실행하여 DB `difficulty`와 DNA `final_grade`가 어긋나는 것을 차단합니다.
- 미지정값을 3점으로 보내는 fallback은 없습니다.
- 수특/수완은 자동으로 킬러(8) 확정하지 않고 최고 준킬러(7)로 제한합니다.
- 비싼 독립 재풀이는 모든 문항에 호출하지 않고 `band_conflict`, 준킬러 이상, 낮은 신뢰도 문항만 선택 검증합니다.
- 선택 검증은 기본 DNA 난이도를 자동 덮어쓰지 않습니다. 2단계 이상 충돌/미판정은 관리자 검토로 보냅니다.
- 검증 API 실패만으로 기본 DNA 난이도가 사라지지 않습니다.
- 분석 검수에서 관리자가 난이도를 수동 수정하면 DNA `admin_fixed=true`로 잠기며 이후 자동계산이 덮어쓰지 않습니다.
- 문제은행의 관리자 난이도 수정 잠금 기능도 기존대로 유지됩니다.

운영 흐름
1. 인식 → 자르기 → AI 분석
2. DNA 운영 난이도 자동 확정
3. 예외 문항만 추가 재풀이 검증
4. 검토 필요하면 REVIEW, 아니면 APPROVED
5. 문제은행 등록 직전 동일 기준 재확인
6. DB difficulty == DNA final_grade 유지
