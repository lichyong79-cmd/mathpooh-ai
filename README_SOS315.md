# SOS315 · 전체 프로그램 진행률 화면 통일

## 공통 표시 항목

- 작업 종류와 작업명
- 현재 처리 단계
- 실제 진행률 또는 예상 진행률
- 완료 수 / 전체 수(총량을 아는 작업)
- 경과 시간
- 예상 남은 시간
- 창 닫기·새로고침 가능 여부

## 진행률 기준

- 자르기, 전체 재분석, 대기열처럼 전체 수를 아는 작업은 실제 완료 수로 계산합니다.
- 단일 서버 요청처럼 전체 수를 알 수 없는 작업은 반드시 `예상 진행률`로 표시합니다.
- 총량이 없는 작업은 작업 종류별 기본시간으로 시작하고, 같은 작업의 실제 소요시간을 브라우저에 학습해 다음 예상시간을 보정합니다.
- 실제 완료 전에는 예상 진행률을 최대 94%로 제한해 완료된 것처럼 보이지 않게 했습니다.

## 통일 범위

- 학생 페이지
- 학부모 페이지
- 관리자 페이지
- 문제은행·AI 분석·문항 자르기
- SOS 진행·결과·현황·AI 생성 문제은행
- 바로미터·리포트·시험 준비 화면
- 전역 장시간 API 작업

## 함께 수정한 문제

- 점 세 개만 표시되던 무진행률 화면 제거
- 영어 대기 문구를 한국어 안내로 통일
- 제목을 `~ 중` 형식으로 통일
- 전역 추정 로더가 실제 `완료/전체` 로더를 덮던 중복 표시 방지
- 학부모 페이지의 독립 로딩 화면을 공통 화면으로 교체

추가 SQL은 없습니다.
