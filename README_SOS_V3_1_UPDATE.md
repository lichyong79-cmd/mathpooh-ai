# SOS v3.1 업데이트

적용 내용

- 시험 입력 화면에 SOS 시험 표지 자동 미리보기 추가
- 입력한 시험명, 학년, 과목, 시험일, 시험시간, 문항수, 총점이 표지에 즉시 반영
- 표지 미리보기 및 인쇄 기능 추가
- 문항영역 자동 초안 UI 추가
- 자동 분석 시작 후 문항별 자동인식/확인필요 상태 표시
- 문항 상태를 클릭해 검수 상태 변경 가능
- 기존 PDF Mapper 이동 버튼 연결

주의

- 실제 PDF 문항번호 OCR/좌표 자동 추출 엔진은 아직 연결 전입니다.
- 표지와 시험지 PDF의 실제 병합은 Supabase Storage 연결 단계에서 구현합니다.
