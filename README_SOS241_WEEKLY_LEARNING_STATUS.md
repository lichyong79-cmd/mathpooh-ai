# SOS241 · SOS 주차/학습현황 통합

SOS240 기준. DB 신규 컬럼/SQL 없이 기존 `sos_training_sessions.target_snapshot` JSON에 SOS 주차 메타데이터를 저장한다.

## 운영 기준
- SOS 학습주차는 달력 기준 월요일~일요일.
- 주차는 마감 강제가 아니라 학습 소속/조회 기준이다.
- 최초 SOS 진단 배정 시 관리자가 `SOS 학습주차`와 `기준 시험`을 선택한다.
- 이후 진단/1차훈련/2차진단/2차훈련/오답/AI 3제 굳히기는 루트 SOS의 주차를 자동 상속한다.
- 과거 세션은 루트 진단 생성일 기준 달력 주차를 자동 계산해 표시한다.

## 관리자
- SOS 학습운영 배정 화면: 학습주차 + 기준시험 선택 추가.
- `/admin/sos-status`: 학생별/주차별 SOS 학습현황 신규.
  - 진행중 / 밀린 SOS / 완료 구분
  - 기준시험, 과목/소단원, 현재 단계, 단계별 상태 표시
  - 전체 SOS 사이클의 주차를 관리자에서 일괄 변경 가능
- SOS 진행관리/결과분석: 주차 필터와 주차/기준시험 표시 추가.
- 기존 배정/진행/결과 탭에 `학습현황` 연결 추가.

## 학생
- 나의 SOS 상단에 `SOS 학습현황` 추가.
- 주차 선택으로 지난 SOS 결과와 현재 학습 조회.
- 현재 해야 할 단계가 `지금 해야 할 SOS`로 크게 표시되며 바로 이어가기 가능.
- 이전 달력 주차에 미완료 단계가 있으면 `밀린 SOS`로 별도 노출.
- 선택한 주차의 기준시험 및 진단/1차/2차/3제 결과를 함께 조회.

## 데이터 호환
- 신규 SQL 없음.
- SOS240 및 과거 세션 구조 유지.
- 주차 메타데이터가 없는 과거 기록은 루트 세션 날짜로 표시만 복원하며 기존 데이터를 임의 변경하지 않는다.
