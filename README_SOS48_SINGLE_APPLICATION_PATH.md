# SOS48 — 단일 자르기 적용 경로 고정

- 기존 문항이 있을 때 `전체 문항 자르기 저장`은 `/api/analysis/start`를 호출하지 않습니다.
- 최초 문항 생성 때만 AI `crop-only`를 호출합니다.
- 화면 빨간 박스, 우측 미리보기, 전체 썸네일, 수동 저장, 자동 분석 저장이 모두 `resolveQuestionCrop()` 한 경로를 사용합니다.
- 한 번 같은 엔진으로 저장된 문항은 `crop_engine_version=single-path-v2`로 표시하여 다시 눌러도 좌표가 재보정되어 흔들리지 않습니다.
- 수동 드래그 저장도 같은 엔진 버전으로 기록됩니다.
