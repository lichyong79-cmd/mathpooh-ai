# SOS123 문항·해설 개별 영역 미리보기

- 실전모의고사 관리 > AI 분석 결과의 `n번 보기`에서 시험지 PDF 전체 페이지를 iframe으로 띄우던 방식을 제거했습니다.
- AI 분석 시 문제와 공식 해설 각각의 페이지 번호와 개별 영역 좌표(`[x,y,width,height]`, 0~1 정규화)를 저장합니다.
- 결과 창에서는 PDF.js로 해당 페이지만 렌더링한 뒤 지정 문항 영역만 잘라서 표시합니다.
- 기존 분석 결과에는 영역 좌표가 없으므로 해당 문항의 `이 문항 재분석`을 한 번 눌러야 개별 문항·해설이 표시됩니다.
