## 1) 「자녀 등록」 → 「자녀 관리」

상단 버튼 이름을 바꾸고, 모달에 **연결된 자녀 목록**을 함께 보여줍니다.
지금 누구와 연결돼 있는지 모른 채 등록만 하던 화면이었습니다.

```
연결된 자녀 2명
  배유담   정신여고 · 고2
  윤동규   화성고 · 고2
연결을 끊어야 할 때는 학원으로 문의해 주세요.
```

## 2) 자녀가 한 명일 때

이름과 상태만 보여주고, 추가는 작게 둡니다.

```
배유담  [연결중]                    ＋ 자녀 추가
```

배정이 끝난 상태면 **연결중**, 아직이면 **배정 전**으로 표시됩니다.

## 3) 자녀가 둘 이상일 때

드롭다운 대신 **탭**으로 바꿨습니다. 한 번 눌러 바로 오갈 수 있습니다.

```
┌──────────┬──────────┐
│  배유담   │  윤동규   │   ＋ 자녀 추가
│  연결중   │  배정 전  │
└──────────┴──────────┘
```

선택된 자녀는 초록색으로 강조됩니다.

## 4) 연결된 자녀가 없을 때 — 강제 등록

예전에는 안내 문구와 버튼만 있고, 학부모가 그냥 머물 수 있었습니다.

이제 **로그인 즉시 자녀 등록 화면이 뜨고 닫을 수 없습니다.**

- 닫기(×) 버튼 없음
- 배경을 눌러도 안 닫힘
- 기본 탭이 **「새 자녀 계정 만들기」**
- 상단에 `등록된 자녀가 없습니다` 안내

빠져나가려면 등록하거나 로그아웃해야 합니다.

## 5) 관리자 · 자녀 연결 끊기

학부모 계정은 학생의 **학부모 연락처**로 자녀를 찾습니다.
번호를 잘못 넣으면 **다른 집 학부모에게 학습기록이 보입니다.**
그런데 끊는 방법이 없었습니다.

학생정보 수정 화면의 학부모 연락처 아래에 **「자녀 연결 끊기」** 버튼을 넣었습니다.

```
이 학생과 학부모 계정(010-0000-0000)의 연결을 끊을까요?

해당 학부모 페이지에서 이 학생이 더 이상 보이지 않습니다.
학생의 학습기록은 그대로 유지됩니다.

저장을 눌러야 실제로 반영됩니다.
```

확인을 누르면 입력란이 비워지고, **저장을 눌러야 반영**됩니다.
실수로 눌러도 저장 전이면 되돌릴 수 있습니다.

연결된 학부모가 없으면 `연결된 학부모 계정이 없습니다` 로 표시됩니다.

## 배포 후 확인

**학부모 계정으로**

1. 자녀가 한 명인 계정 → 이름과 `연결중` 배지, 오른쪽에 작은 `＋ 자녀 추가`
2. 자녀가 둘인 계정 → 탭으로 오갈 수 있는지
3. 자녀가 없는 계정 → 로그인하자마자 등록 화면이 뜨고 닫히지 않는지

자녀 없는 계정이 없으면, 관리자에서 어느 학생의 학부모 연락처를 지워
일시적으로 만들어 확인하실 수 있습니다.

**관리자에서**

학생정보 → 학생 하나 수정 → 학부모 연락처 아래 `자녀 연결 끊기` 확인.
끊은 뒤 **저장**하고, 해당 학부모 페이지에서 그 학생이 사라졌는지 보세요.

## 참고

학부모 쪽 모달에는 연결 끊기를 넣지 않았습니다.
학부모가 스스로 끊으면 학원이 모르는 사이 연결이 사라져
학습 안내나 상담이 누락될 수 있어서입니다.
모달에 `연결을 끊어야 할 때는 학원으로 문의해 주세요` 안내를 넣었습니다.

필요하시면 학부모 쪽에도 추가할 수 있습니다.
