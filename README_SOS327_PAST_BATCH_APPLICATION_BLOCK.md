# SOS327 - 지난 5회 묶음 신청 차단

## 수정 내용
- 공개 신청 페이지(`/apply`)의 신청 가능 목록에서 **1회차 시작일이 이미 지난 5회 묶음**을 제외합니다.
- 학부모 포털의 `신청 가능한 SOS 5회 프로그램`에서도 동일하게 지난 묶음을 제외합니다.
- 화면 조작이나 오래 열린 탭 등으로 POST 요청을 직접 보내더라도 서버에서 다시 1회차 시작일을 확인하여 차단합니다.
- 기준 날짜는 Vercel 서버 UTC가 아니라 **대한민국(Asia/Seoul) 날짜**를 사용합니다.
- 신청 시작/종료 기간 조건도 학부모 포털 목록에 동일하게 적용합니다.

## 기준
- 1회차 시작일 < 오늘(KST): 신규 신청 불가
- 1회차 시작일 = 오늘(KST): 신청기간이 열려 있으면 신청 가능
- 1회차 시작일 > 오늘(KST): 신청기간이 열려 있으면 신청 가능
