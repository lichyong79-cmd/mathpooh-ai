# SOS354 학생 화면 디자인 정돈

- SOS352의 관리자 `시험 시작` 대형 버튼을 포함합니다.
- SOS353의 부정행위 의심 로그 요약 표시를 포함합니다.
- 학생 화면의 기본 글꼴을 한글 가독성이 좋은 Pretendard 우선 순서로 정리했습니다.
- 전체 배경과 카드 영역을 흰색·짙은 남색·중립 회색 중심으로 정돈했습니다.
- SOS 초록색은 활성 메뉴, 진행 상태, 주요 실행 버튼에만 사용합니다.
- 상단 메뉴를 더 얇고 단정한 탭 형태로 바꾸고 불필요한 강조선을 제거했습니다.
- 시험 일정 카드는 날짜, 시험 정보, 상태 및 실행 버튼의 정보 우선순위가 바로 보이도록 간격과 대비를 조정했습니다.
- 모바일 화면의 기존 응시 동선과 반응형 배치는 그대로 유지합니다.

## 적용

기존 프로젝트에 전체 파일을 덮어쓴 뒤 빌드하고 배포합니다.
