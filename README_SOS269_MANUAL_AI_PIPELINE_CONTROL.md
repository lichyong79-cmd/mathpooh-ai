# SOS269 · AI 변형문항 제작 공정 수동 제어

- AI 생성 문제은행의 각 생성 작업에 관리자 수동 공정 버튼 추가
- 현재단계 다시 실행
- 텍스트부터 재시작
- 텍스트 승인 → 조판
- 조판 승인 → 재풀이
- 최종검증 강제승인 → READY
- 버튼 클릭 시 단순 상태 변경이 아니라 해당 공정을 즉시 실행
- 저장된 텍스트/조판 결과 수량 표시 및 중간 결과 펼쳐보기 추가
- 최종검증 강제승인은 조판 결과가 모두 존재할 때만 활성화되며 확인창을 거침
- 수동 재실행 시 attempt_count를 초기화해 자동 재시도 횟수 제한에 막히지 않도록 처리

추가 SQL 없음. SOS268의 supabase-v3.8-ai-generation-pipeline-v2.sql이 이미 적용되어 있어야 합니다.
