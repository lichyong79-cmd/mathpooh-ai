# SOS244 난이도 검증실패 안전처리

- 표본 재풀이 결과에 `검증실패`를 별도 집계합니다.
- AI 응답이 비거나 5xx 오류가 나면 같은 요청을 1회 자동 재시도합니다.
- 그래도 실패하면 기존 난이도를 절대 변경하지 않고 실패 카드로 남깁니다.
- 실패 카드에서 `이 문항 다시 검증`을 누를 수 있습니다.
- `검증실패 n문항 다시 검증`으로 실패 문항만 일괄 재시도할 수 있습니다.
- 표본에 검증실패가 1개라도 남아 있으면 `② 검증 엔진 전체 재판정` 버튼을 잠급니다.
- 미판정/검토필요와 검증실패를 서로 분리합니다.
- 난이도 관리 화면 버전 표기를 SOS244로 갱신했습니다.
- DB 스키마 변경 및 신규 SQL 없음.
