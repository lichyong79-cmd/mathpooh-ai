# SOS325 - 일부 문제은행 등록 후 최종 AI분석 화면 유지

## 증상
AI 문항분석 완료 후 일부 문항만 문제은행에 등록하면, 재조회 시 최종 3단계가 아니라 1단계 AI 문제인식 화면으로 돌아감.

## 원인
`/api/problem-bank/register`가 `source_analysis.current_step`을 `문제은행 등록 완료`로 저장했지만, 작업장 로딩 코드는 `3단계` 문자열이 있을 때만 3단계로 복원했음.

## 수정
- 문제은행 등록 시 `current_step`을 `3단계 · 문제은행 등록 완료`로 저장.
- 기존 데이터 호환을 위해 작업장 로딩 시 `문제은행 등록` 문자열, 실제 등록 문항 존재, 또는 최종 분석 상태 문항 존재 시 3단계로 복원.
- 일부 등록 후 남은 등록대기/검토보류 문항을 계속 처리할 수 있도록 최종 AI분석/문제은행 연결 화면 유지.

## 중요
자르기 엔진, question-anchors, crop 생성/저장 로직은 변경하지 않음.
