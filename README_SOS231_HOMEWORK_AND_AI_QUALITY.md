# SOS231 · 1차 통과자 숙제 + AI 유사문항 검증/표시

## 1차 훈련 통과자
- 1차 훈련 + 오답 완료 후 목표 바로미터 달성 시 2차 훈련으로 보내지 않음.
- AI 유사문항 3제 HOMEWORK 세션을 자동 생성.
- 학생이 직접 숙제를 시작하고, 기존 공통 성적표/오답 교정 규칙으로 마무리.
- 3제 완료 후 해당 주 SOS 공략 완료.

## 1차 훈련 미달자
- AI 유사문항 10제로 2차 정식훈련.
- 2차 훈련 + 오답 후 해당 주 SOS 종료. 3차 훈련 없음.

## AI 유사문항 품질 게이트
- 정답은 -999~999 정수 한 개만 허용.
- 문제/풀이 빈값, 깨진 LaTeX 명령, 지나치게 짧은 문항 거부.
- 생성 후 별도의 AI 최종검수 단계에서 출제자 답을 믿지 않고 독립 재풀이.
- 조건 충분성, 모순 여부, 유일해, 실제 계산값, claimed answer 일치를 모두 확인.
- 하나라도 실패하면 전체 batch를 폐기하고 최대 3회 재생성.

## 학생 표시
- AI 유사문항 화면에 `AI 유사문항 · 2차 훈련` 또는 `AI 유사문항 숙제` 배지 표시.
- 가능한 경우 `1차 훈련 N번에서 파생` 표시.
- `핵심유형`과 생성 이유를 함께 표시해 왜 이 문제가 나왔는지 이해할 수 있게 함.
