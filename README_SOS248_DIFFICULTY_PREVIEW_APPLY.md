# SOS248 — 전체 난이도 미리보기 → 최종 적용 분리

핵심
- 기존 ② 버튼은 dryRun=false로 즉시 DB를 변경했으나 SOS248에서 제거.
- ② 전체 재판정 미리보기: 전 문항 AI 재풀이, dryRun=true, DB 변경 0건.
- 완료 후 현재 분포 / 예상 분포 / 주요 이동 / 유지·변경·검토·미판정·실패 집계 표시.
- ③ 최종 적용 버튼은 미리보기 결과가 있을 때만 표시.
- 최종 적용은 AI를 다시 호출하지 않고 미리보기의 동일 판정값을 그대로 저장.
- 미리보기 후 난이도가 수동 변경된 문항(stale), 관리자 확정 문항, 검토필요/미판정/실패는 자동 적용하지 않음.
- SOS247 max_output_tokens fallback + SOS246 바로미터 timeout 안전장치 유지.
