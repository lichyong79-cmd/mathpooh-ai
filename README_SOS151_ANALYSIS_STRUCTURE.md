- 시험성적 분석: 상단 공통 실전모의고사 헤더와 관리 탭을 제거하고 시험 결과 전광판만 표시

  - 현재 SOS 전략
  - 진단 3문항 / 훈련 10문항 이력 및 정답률
  - 과목·단원 완성도
  - 모의고사 득점 변화
