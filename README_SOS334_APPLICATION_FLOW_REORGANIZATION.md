# SOS334 - 신청 흐름 재정리

## 목적
관리자 회차/모집/신청 처리와 학부모 전체·회차별 신청 흐름을 하나의 순서로 정리했습니다.

## 핵심 변경
- 기존 `learning_cycles` 회차는 삭제/초기화/마이그레이션하지 않습니다.
- 관리자 메뉴 명칭을 `실전모의고사 신청`, `SOS 신청 관리`, `회차 관리`로 분리했습니다.
- SOS 신청 관리 상단에 `회차 관리 → 모집 구성 → 신청 열기 → 신청 접수 → 결제 확인/자동배정` 흐름을 표시합니다.
- 새 모집 구성은 회차 관리에서 이미 만든 기존 회차 5개를 선택하는 방식입니다.
- 현재/예정 회차를 우선 표시하고 기존·과거 회차는 접어서 확인할 수 있습니다. 과거 회차 데이터는 그대로 유지됩니다.
- 모집 카드에서 회차별 `신청 가능/종료` 상태를 표시합니다.
- 학부모는 남은 회차 전체 또는 개별 회차를 신청할 수 있고, 지난 회차는 `종료` 상태로 선택 불가입니다.
- 학부모는 결제 확인 전 `REQUESTED` 상태에서 직접 신청 취소할 수 있습니다. 취소 후 재신청 가능합니다.
- 관리자도 `REQUESTED` 신청을 취소할 수 있습니다.
- 결제 확인/등록 완료 뒤 취소·환불은 학부모 화면에서 막고 관리자 문의 문구를 표시합니다.
- 관리자 신청 처리에서는 신규 학생 자동 생성 UI를 제거하고, 학부모가 연결한 자녀 계정을 기준으로 등록하도록 정리했습니다. 과거 데이터 호환용 서버 fallback은 유지합니다.
- 실전모의고사 신청 화면에서 시험지명 앞에 UI가 추가로 붙이던 `N회 ·` 표기를 제거했습니다. DB 시험지명 자체는 변경하지 않습니다.
- 관리자에서 `학부모 신청 화면 보기`는 `/p?tab=apply`로 바로 연결됩니다.
