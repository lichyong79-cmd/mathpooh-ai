# SOS 148 · 응시 동의 시간과 웹 로그 정리

- 실전모의고사 진행의 `시작 시각`을 `응시 동의`로 변경했습니다.
- 학생이 응시 안내에 동의한 순간 `exam_consent` 로그를 저장합니다.
- 관리자 시작 전 대기 진입, 시험 시작, 답안 변경 저장, 제출 완료 로그를 추가했습니다.
- 학생별 화면 이탈 횟수와 총 이탈 시간을 진행 표에서 바로 확인할 수 있습니다.
- 웹 로그 목록에 응시 동의/대기/시작/저장/제출 이벤트를 함께 표시합니다.
- 점수·결과 버튼이 좁은 화면에서 세로로 깨지지 않도록 점수와 결과보기를 2줄 고정 버튼으로 정리했습니다.
