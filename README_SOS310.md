# SOS310 · 학부모 전용 5회 묶음 신청

## 최종 운영 구조

1. 관리자가 `회차 관리`에서 시험 일정 5개를 먼저 만듭니다. 이때 시험지는 없어도 됩니다.
2. `SOS 5회 신청`에서 운영 회차를 정확히 5개 선택해 묶음을 만듭니다.
3. `신청 열기`를 누르면 학부모 페이지와 로그인 전 신규 신청 페이지에 공개됩니다.
4. 학부모가 자녀 정보로 5회 묶음을 신청합니다.
5. 관리자가 입금을 확인하고 `입금완료·등록`을 누릅니다.
6. 기존 학생은 계정을 연결하고, 신규 학생은 학생·학부모 계정을 자동 생성합니다.
7. 5개 운영 회차가 학생에게 등록됩니다.
8. 매주 시험지를 해당 회차에 연결하면 등록 학생에게 자동 배정됩니다.

시험이 먼저 연결된 경우에는 입금완료 시 배정하고, 입금완료가 먼저인 경우에는 시험 연결 시 배정합니다.

## 화면 변경

- 학생: 포스터·신청 기능 제거, 현재 등록된 5회 묶음과 5개 회차 표시
- 학부모: 포스터, SOS 5회 신청, 접수·등록 상태 표시
- 로그인 전: `/apply` 신규 학부모 신청서
- 관리자: `SOS 5회 신청` 메뉴에서 묶음 생성·공개·입금확인·계정연결

## 배포

1. 기존 프로젝트에 SOS310을 덮어쓰고 배포합니다.
2. Supabase SQL Editor에서 `supabase-sos310-five-cycle-applications.sql`을 한 번 실행합니다.
3. SOS309 속도 인덱스를 아직 실행하지 않았다면 `supabase-sos309-performance-indexes.sql`도 한 번 실행합니다.

SQL 실행 전에도 기존 시험·학습 기능은 유지되지만, SOS310 신청 메뉴는 새 테이블 안내 오류를 표시합니다.
