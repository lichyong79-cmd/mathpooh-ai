# SOS341 시험 파일 저장 RLS 오류 수정

## 원인

- Storage 보안 정책은 시험 파일 쓰기를 `service_role` 전용으로 제한합니다.
- 시험 등록 화면만 브라우저에서 `exam-files` 버킷에 직접 업로드하고 있어 403 RLS 오류가 발생했습니다.

## 수정

- 관리자 권한을 확인하는 `/api/admin/exam-files` 서버 업로드 API를 추가했습니다.
- 시험지·해설지·원본 파일은 서버의 service role을 통해 비공개 버킷에 저장합니다.
- 업로드 실패 시 새로 만들어진 빈 시험 행과 일부 업로드된 파일을 자동 정리합니다.
- Storage 정책을 공개하거나 느슨하게 변경하지 않습니다.

## 적용

- 별도 SQL 실행 없이 코드만 배포하면 됩니다.
- 배포 후 관리자에서 시험을 다시 등록해 확인합니다.
