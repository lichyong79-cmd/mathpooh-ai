# AI 문제은행 v2 — 문항 자동 자르기 핵심 수정

## 변경 핵심
- AI가 반환한 사각형 좌표를 그대로 사용하지 않음
- 페이지별로 문항을 묶고 1단/2단 편집을 자동 판별
- 같은 단의 다음 문항 시작점 직전까지 현재 문항 영역으로 자동 보정
- 선택지, 보기, 그래프, 도형이 잘리는 현상 감소
- 다음 문항이 현재 문항 이미지에 섞이는 현상 감소
- 0~1 비율 좌표와 0~100 백분율 좌표를 모두 정규화
- 비정상 좌표는 기존 검수 경고 유지

## 사용 흐름
시험지 업로드 → AI 분석 실행 → 자동 보정된 박스 확인 → 틀린 박스만 수정 → 문제은행 등록
