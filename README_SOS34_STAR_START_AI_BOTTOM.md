# SOS34 - ★ 시작점 + AI 끝점 크롭

## 수정 내용
- PDF 미리보기의 `DOMMatrix is not defined` 오류를 피하기 위해 모든 클라이언트 PDF.js 로딩을 legacy 빌드로 통일했습니다.
- 시험지에서 `★`가 붙은 항목만 등록 문항으로 취급합니다.
- `★`는 문항의 확정 시작점입니다.
- 다음 별까지 자동으로 자르지 않고, AI가 현재 문항의 실제 마지막 본문/선택지/도형 위치를 판정합니다.
- `★`가 없는 예제와 설명은 문항으로 등록하지 않습니다.
- `_해설지.pdf`는 기존대로 문항 번호별 정답·단원·유형 분석에 함께 사용합니다.

## 한글 원본 작성 규칙
- 별은 이미지가 아니라 문자 `★`를 사용합니다.
- 실제 등록할 문항번호 바로 앞 또는 바로 위에 배치합니다.
- 예제에는 별을 넣지 않습니다.
