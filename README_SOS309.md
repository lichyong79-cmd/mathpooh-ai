# SOS309 성능 개선

SOS307 기능과 SOS308 사용자 안내를 유지하면서 학생·학부모 화면의 반복 조회량을 줄였습니다.

## 적용 내용

- 시험 시작 대기 중 전체 학생 포털을 2초마다 다시 읽던 동작을 5초 간격의 시험 상태 전용 조회로 변경
- 시험 목록의 문항 분석 정보를 시험별 반복 조회하지 않고 한 번에 조회
- SOS AI 생성 대기 중 전체 훈련 이력·문항·이미지를 다시 읽지 않고 작업 상태만 확인
- 현재 훈련 또는 사용자가 펼친 이력의 문항 이미지만 서명 URL 생성
- 학생 메인의 무거운 진단·지도·훈련 컴포넌트를 필요할 때 로드
- 학부모 포털의 시험·훈련·AI 작업 조회에 표시 용도의 상한 적용
- 학생·학부모 반복 조회용 보조 DB 인덱스 추가

## 배포

1. 프로젝트를 배포합니다.
2. Supabase SQL Editor에서 `supabase-sos309-performance-indexes.sql`을 한 번 실행합니다.
3. 학생 계정에서 메인, 시험 대기, SOS 학습 탭을 확인합니다.
4. 학부모 계정에서 자녀 전환과 최근 학습 내역을 확인합니다.

SQL은 기존 행을 수정하거나 삭제하지 않고 조회용 인덱스만 추가합니다.

## 검토 메모

- AI 생성 작업은 동시 실행 기본값 3, 상한 4 구조를 유지합니다.
- 난이도 관리 화면은 전체 문제은행을 한 번에 다루므로 학생 화면보다 첫 로딩이 무겁습니다. 사용자 학습 속도와는 분리되어 있지만, 문제가 계속 늘어나면 서버 페이지네이션으로 별도 전환하는 것이 좋습니다.
- 관리자 화면은 기능이 한 파일에 많이 모여 있어 초기 자바스크립트가 큽니다. 이번 버전에서는 사용자 체감 병목을 우선 제거했고, 관리자 화면 분리는 다음 구조 개선 대상으로 남겼습니다.
