SOS116R 적용 안내

기준 버전
- SOS115_ADMIN_MENU_REORGANIZED를 그대로 기준으로 사용합니다.

수정 내용
- 관리자 메뉴의 상위/하위 구조, 항목 순서, 클릭 기능과 화면 연결은 SOS115 그대로 유지합니다.
- MATSPU 오타를 MATHPOOH로 수정했습니다.
- SOS 풀네임을 SCORE OPTIMIZATION SYSTEM으로 표시했습니다.
- 메뉴, 상위/하위 구분 제목, 본문 표와 버튼의 글자 크기만 키워 가독성을 개선했습니다.

변경하지 않은 내용
- 메뉴 재정렬 없음
- 탭 이동 경로 변경 없음
- 기능 로직 변경 없음
- DB 및 SQL 변경 없음

적용
1. 현재 프로젝트를 백업합니다.
2. 이 압축파일의 내용을 프로젝트에 덮어씁니다.
3. npm install 또는 npm ci를 실행합니다.
4. npm run build로 확인합니다.
5. Git 커밋 후 배포합니다.

빌드 확인
- Next.js production build 및 TypeScript 검사 통과

긴급 오류 수정
- DB 시험 목록 로딩 전에 사용되던 demo-1/demo-2 임시 시험을 제거했습니다.
- 시험 배정 API에 UUID 검사를 추가했습니다.
- invalid input syntax for type uuid: "demo-1" 오류를 차단했습니다.
- 문제등록 메뉴는 SOS115의 AI 문제등록 업로드 화면으로 연결됩니다.
- AI 분석 화면에서 관리자로 이동하면 /admin의 해당 메뉴로 정확히 돌아갑니다.
