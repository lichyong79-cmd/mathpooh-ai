SOS116R 적용 안내

기준 버전
- SOS115_ADMIN_MENU_REORGANIZED를 그대로 기준으로 사용합니다.

수정 내용
- 관리자 메뉴의 상위/하위 구조, 항목 순서, 클릭 기능과 화면 연결은 SOS115 그대로 유지합니다.
- MATSPU 오타를 MATHPOOH로 수정했습니다.
- SOS 풀네임을 SCORE OPTIMIZATION SYSTEM으로 표시했습니다.
- 메뉴, 상위/하위 구분 제목, 본문 표와 버튼의 글자 크기만 키워 가독성을 개선했습니다.

변경하지 않은 내용
- 메뉴 재정렬 없음
- 탭 이동 경로 변경 없음
- 기능 로직 변경 없음
- DB 및 SQL 변경 없음

적용
1. 현재 프로젝트를 백업합니다.
2. 이 압축파일의 내용을 프로젝트에 덮어씁니다.
3. npm install 또는 npm ci를 실행합니다.
4. npm run build로 확인합니다.
5. Git 커밋 후 배포합니다.

빌드 확인
- Next.js production build 및 TypeScript 검사 통과

긴급 오류 수정
- DB 시험 목록 로딩 전에 사용되던 demo-1/demo-2 임시 시험을 제거했습니다.
- 시험 배정 API에 UUID 검사를 추가했습니다.
- invalid input syntax for type uuid: "demo-1" 오류를 차단했습니다.
- 문제등록 메뉴는 SOS115의 AI 문제등록 업로드 화면으로 연결됩니다.
- AI 분석 화면에서 관리자로 이동하면 /admin의 해당 메뉴로 정확히 돌아갑니다.
- 문제은행 상단의 관리자 버튼도 로그인 화면(/)이 아닌 관리자 메인(/admin)으로 이동합니다.

관리자 메뉴 통일
- SOS 문제은행과 AI 분석 화면에도 관리자 공통 왼쪽 사이드바를 적용했습니다.
- AI 분석 화면에서는 넓은 작업공간을 위해 사이드바를 접고 펼칠 수 있습니다.
- 현재 화면에 맞는 메뉴가 활성 표시됩니다.
- 관리자 내부 메뉴는 /admin?menu=메뉴ID로 직접 이동합니다.
- 문제등록, AI 분석, SOS 문제은행 버튼은 각각 실제 기능 화면으로 연결됩니다.
SOS118 변경사항
- 문제등록 화면의 '훈련 과정(기초연산/대표유형/실전유형/준킬러/킬러)' 선택 영역을 제거했습니다.
- 신규 문제 등록 시 훈련 단계를 임의로 저장하지 않습니다.
- 훈련 단계는 이후 SOS 학습관리/추천 과정에서 문항 DNA를 기준으로 분류합니다.
- 기존 문제등록, 파일 업로드, AI 분석 연결 기능은 그대로 유지합니다.
SOS119 변경사항
- AI 분석/SOS 문제은행 공통 사이드바를 흰색·연회색 기반으로 변경했습니다.
- 매쓰푸 녹색은 선택 메뉴, 아이콘, 배지 등 포인트 영역에만 적용합니다.
- AI 분석 화면에 남아 있던 파랑·보라 상태 색상을 매쓰푸 녹색 계열로 통일했습니다.
SOS119 최종 변경사항
- 관리자 전체 사이드바를 mathpooh.com 관리자 화면처럼 검정 배경으로 통일했습니다.
- 메뉴 글자는 흰색·회색, 선택 항목은 어두운 카드와 매쓰푸 녹색 테두리로 표시합니다.
- 일반 관리자, AI 분석, SOS 문제은행에서 동일한 사이드바 톤을 사용합니다.
- 문제등록의 불필요한 훈련 과정 선택 제거도 포함되어 있습니다.
SOS120 변경사항
- 실전모의고사 AI 문항분석 화면의 제목과 설명을 현재 작업에 맞게 수정했습니다.
- AI 문항분석 화면의 중복 시험입력 버튼을 제거했습니다.
- 상단의 기능 없는 도움말/알림 버튼을 제거하고 새 시험 버튼은 시험 목록·입력 화면에서만 표시합니다.
- AI 분석 통계는 분석 대상/완료/필요/분석 문항 기준으로 표시합니다.
- 가로 스크롤 표를 시험별 카드형 레이아웃으로 바꾸어 진행률·상태·관리 버튼 겹침을 제거했습니다.
SOS121 변경사항
- 실전모의고사 AI 문항분석 완료 버튼을 '분석 결과 확인' 버튼으로 변경했습니다.
- 문항별 대·중·소단원, 세부 주제, 문항 유형, 난이도, 정답, 신뢰도, AI 핵심 풀이를 한 화면에서 확인할 수 있습니다.
- 분석 결과 창에서 원하는 한 문항만 재분석할 수 있습니다.
- 새 분석부터 공식 답지의 해당 문항 정답과 핵심 풀이 요약을 분석 데이터에 함께 저장합니다.
- 기존 분석 결과는 그대로 호환되며 정답·요약이 없는 문항만 재분석하면 값이 채워집니다.
- 별도 SQL 실행은 필요하지 않습니다.
