# SOS360 · AI 생성 대기열 가속

- AI 문항 생성 동시 처리 기본값을 3명에서 4명으로 높였습니다.
- 한 묶음을 만든 작업은 대기열 뒤로 이동시켜 7명이 몰려도 특정 학생만 계속 선점하지 않게 했습니다.
- 학생 화면의 AI 생성 완료 확인 주기를 45초에서 15초로 단축했습니다.
- 문항 정확도 검증 및 3문항 단위 안전 생성은 그대로 유지합니다.

## 운영 설정

외부 스케줄러에서 `/api/cron/sos-ai-generation` 호출 주기를 10분에서 1분으로 변경하세요.
`SOS_AI_GENERATION_CONCURRENCY` 환경변수가 기존에 `3`으로 설정돼 있다면 `4`로 바꾸거나 삭제해야 새 기본값 4가 적용됩니다.

별도 Supabase SQL은 필요하지 않습니다.
