# SOS232 · 관리자 진행탭 단계별 리셋

- 진행탭 각 단계에 `↻ 단계`, `↻ 오답` 버튼 추가
- 결과 상세에 `이 단계부터 다시 / 오답만 다시 / SOS 전체 초기화` 추가
- 단계 리셋: 선택 단계 응시결과 초기화 + 이후 자식 단계 자동 삭제
- 오답 리셋: 최초 응시 결과 유지 + 오답 기록만 초기화 + 이후 자식 단계 자동 삭제
- SOS 전체 초기화: 현재 SOS 루트 진단을 ASSIGNED 상태로 되돌리고 이후 단계 자동 삭제
- 학생 바로미터를 해당 단계 시작 시점으로 복원
- 삭제된 난이도 이벤트를 기준으로 문제은행 동적 난이도 재계산
- 관리자 리셋 감사로그 `sos_admin_reset_logs` 저장
- 실행 전 `supabase-v3.5-sos-admin-reset-audit.sql` 적용 필요
