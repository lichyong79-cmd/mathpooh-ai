# SOS 시험관리 가독성·저장·PDF 확인 개선

적용 내용
- 전체 관리자 화면 글자 크기 확대
- 시험 목록/상태/버튼/입력폼 가독성 개선
- 시험 수정 및 삭제 결과를 localStorage에 저장해 새로고침 후에도 유지
- 신규 시험 기본 시험시간을 100분으로 변경
- 시험지·해설지 PDF 선택 후 미리보기 모달 추가
- 시험 목록에서 시험지/해설지 등록 상태를 각각 표시
- 잘못 생성된 루트 app 폴더를 제거하고 PDF Mapper를 src/app/pdf-mapper로 이동

주의
- 시험 기본정보는 현재 브라우저 localStorage에 유지됩니다.
- PDF 원본 데이터는 아직 Supabase Storage에 업로드되지 않으므로 브라우저를 완전히 다시 연 뒤에는 PDF를 다시 선택해야 할 수 있습니다.
