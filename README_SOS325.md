## 1) 휴원이 저장만 되고 아무 효과가 없었습니다

학생 상태에 `정상 / 휴원 / 퇴원` 이 이미 있었고 저장도 됐습니다.
그런데 **어디에서도 확인하지 않았습니다.**

`active` 값은 퇴원일 때만 false가 되고, 그마저 학생 접근을 막는 데 쓰이지 않았습니다.
**휴원으로 바꿔도 학생은 그대로 로그인해서 학습을 계속했습니다.**

### 고친 방법

학생 포털 진입 시 상태를 확인합니다.

```
휴원 → "현재 휴원 중입니다. 학습을 다시 시작하려면 학원으로 문의해 주세요."
퇴원 → "퇴원 처리된 계정입니다. 학원으로 문의해 주세요."
```

**학습기록은 그대로 둡니다.** 복귀할 때 상태만 `정상`으로 되돌리면
진단 결과, 바로미터, 훈련 이력이 그대로 이어집니다.

### 학부모 화면에도 표시

자녀가 휴원 중이면 배지가 `휴원 중` 으로 바뀝니다.
아무 표시 없이 학습이 멈추면 학부모는 시스템 오류로 오해합니다.

## 2) 학부모 탈퇴 — 학생 기록은 보존

관리자 → 학생정보 관리 상단에 **「학부모 탈퇴」** 버튼이 생깁니다.

전화번호를 입력하면 확인창이 뜹니다.

```
010-0000-0000 학부모 계정을 탈퇴 처리할까요?

· 학부모 로그인 계정이 삭제됩니다
· 연결된 자녀와의 연결이 해제됩니다
· 자녀의 학습기록은 그대로 유지됩니다

되돌릴 수 없습니다.
```

### 처리 순서가 중요합니다

```
1) 연결된 자녀의 parent_phone 을 비운다   ← 먼저
2) 학부모 인증 계정을 삭제한다
```

계정을 먼저 지우면 **어떤 자녀가 연결돼 있었는지 알 수 없습니다.**
그래서 연결 해제를 먼저 하고, 처리 후 어떤 자녀의 연결이 풀렸는지 알려줍니다.

```
학부모 계정을 삭제했습니다. 자녀 2명의 학습기록은 그대로 유지됩니다.

연결 해제된 자녀 : 배유담, 윤동규
```

### 왜 학생 기록을 남기는가

학습기록은 **학생의 것이지 학부모의 것이 아닙니다.**
학부모가 바뀌거나(재혼·조부모 양육 등) 형제자매가 이어서 다닐 수도 있고,
재등록 시 이전 진단 결과가 있어야 학습을 이어갈 수 있습니다.

학생 자체를 지워야 한다면 학생정보에서 **퇴원 처리**를 쓰시면 됩니다.

## 배포 후 확인

**휴원 처리**

1. 관리자 → 학생정보에서 학생 하나를 `휴원` 으로 바꾸고 저장
2. 그 학생 계정으로 로그인 → 안내 문구가 뜨고 학습 화면이 안 열리는지
3. 학부모 계정에서 그 자녀 배지가 `휴원 중` 인지
4. 다시 `정상` 으로 되돌리면 학습기록이 그대로인지

**학부모 탈퇴**

테스트용 학부모 계정을 하나 만들어 확인하시는 편이 안전합니다.
탈퇴 후 학생정보에서 해당 학생들의 학부모 연락처가 비었는지,
학생 학습기록은 그대로인지 보세요.

## 참고 · 남은 판단

**퇴원 학생의 계정 정리**

지금은 퇴원해도 로그인 계정이 남습니다(접근은 막힙니다).
개인정보 보호 관점에서는 일정 기간 후 계정을 삭제하는 편이 낫습니다.
개인정보처리방침(SOS323)에 **수강 종료 후 1년** 으로 적어두었으니,
그 시점에 정리하는 절차를 나중에 만드시면 됩니다.

**학부모 스스로 탈퇴**

지금은 관리자만 할 수 있습니다.
개인정보 보호법상 정보주체의 삭제 요구권이 있으므로,
학부모가 요청하면 관리자가 처리하는 방식으로도 충족됩니다.
다만 학부모 페이지에 탈퇴 버튼을 두는 편이 더 명확하니,
필요하시면 추가하겠습니다.
