# SOS213 — 진단 앞단 정리

이번 버전은 훈련문항 추천을 붙이기 전에 1차 진단 흐름을 정리한다.

- 관리자가 고른 3문항은 클릭 순서가 아니라 난이도 낮은 순서로 자동 재정렬한다.
- 학생 진단 화면에서 원본 시험지 문제번호 영역을 가리고 SOS 순번(1/2/3번)만 사용한다.
- 진단 완료 후 학생에게 문항별 정오답, 내 답, 정답, 풀이시간, 사진제출 시간을 표시한다.
- 진단 제출 직후 실행되던 구형 '같은 소단원 10문항 자동훈련' 로직을 제거했다.
- 진단 완료 응답은 `AI_WEAKNESS_ANALYSIS_PENDING`을 반환해 다음 단계가 AI 취약점 분석임을 명확히 했다.
- 새 DB 컬럼/SQL 없음.
