# SOS332 · 회차 관리 + 전체/회차별 신청

- 관리자 회차 관리: 생성 + 수정 + 안전 삭제
- 5회 프로그램: 기존 묶음의 회차 구성 수정 및 묶음 삭제 지원
- 과거 회차가 포함되어도 신청 화면에 프로그램을 표시하되, 지난 회차는 `종료`로 표시하고 선택 불가
- 학부모 신청: `남은 회차 전체 신청` 또는 `회차별 신청`
- 회차별 신청 금액: 5회 총액을 5로 나눈 1회 금액 × 선택 회차 수
- 결제 확인/등록 시 선택한 회차의 시험만 학생에게 배정
- 기존 신청 데이터는 application_mode=ALL로 호환

## SQL
기존 DB에는 `supabase-sos332-cycle-selection.sql`을 1회 실행하세요.

## 주의
회차 삭제는 5회 프로그램이나 시험과 연결되어 있으면 차단됩니다. 연결을 먼저 해제한 뒤 삭제합니다.
