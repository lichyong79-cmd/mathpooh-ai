# SOS31 - 크롭 롤백 + 분석 복구

## 기준
- 크롭 흐름은 SOS(27) 상태로 복구했습니다.
- SOS(29)~SOS(30)의 AI 크롭 재검수 라우트와 자동 재크롭 흐름은 포함하지 않았습니다.
- 문항 분석 API만 안정화했습니다.

## 분석 API 안정화
- OpenAI 구조화 JSON 응답 1차 시도
- 빈 응답, 잘린 응답, JSON 파싱 실패 시 일반 JSON 형식으로 1회 자동 재시도
- 코드블록이나 설명이 섞인 응답에서도 JSON 객체 추출
- OpenAI 응답 본문 자체가 깨졌을 때 명확한 오류 표시
- 해설 PDF가 있을 때 정답 확인에 사용
- 분석 실패가 크롭 좌표를 수정하지 않음
