# SOS342 시험 목록 안전 삭제 및 빈 시험 일괄 정리

## 발생 원인

- SOS341 이전에는 신규 시험의 기본 DB 행을 먼저 만든 뒤 파일을 브라우저에서 업로드했습니다.
- Storage RLS로 파일 업로드가 실패해도 먼저 생성된 빈 시험 행이 남아 목록에 중복처럼 누적됐습니다.

## 추가 기능

- 시험명 바로 아래에 `이 시험 삭제` 버튼을 배치했습니다.
- 목록 상단에 `빈 작성중 시험 N개 일괄 삭제` 버튼을 추가했습니다.
- 빈 시험 기준은 `작성중`이며 시험지·해설지·한글 원본이 모두 없는 시험입니다.
- 응시기록, 학생배정 또는 회차연결이 있는 시험은 서버에서 삭제를 차단합니다.
- 안전하게 삭제된 시험은 연결된 Storage 파일도 함께 정리합니다.

## 포함 사항

- SOS341의 관리자 서버 경유 시험 파일 업로드 수정도 포함합니다.
- 앞으로 저장 실패로 빈 시험이 새로 누적되는 문제도 방지합니다.
- 별도 SQL은 필요 없습니다.
