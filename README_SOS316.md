# SOS316 · 문항 경계 회귀 오류 수정

## 원인

SOS313에서 좌·우 누락 문항을 찾기 위해 전체 PDF 숫자 탐색 결과를 기존 문항의
표시·자르기 경계에도 그대로 사용했습니다. 선택지·분수·본문 속 숫자가 다음 문항번호로
오인식되면 앞 문항 선택지가 잘리고 다음 문항이 빈 공간부터 시작했습니다.

## 수정

- 기존 문항 경계와 누락 탐색을 분리
- 기존 문항은 현재 문항번호 목록으로 제한해 앵커 재계산
- 누락 전체 탐색은 `좌·우 누락 자동 확인·복구`를 눌렀을 때만 실행
- 각 단에서 반복되는 실제 문항번호 x축을 찾아 그 축의 번호만 경계 후보로 사용
- 선택지·분수·수식 속 숫자를 다음 문항 시작점으로 채택하지 않도록 차단
- 같은 단 마지막 문항은 기존 인식 사각형이 있으면 페이지 하단까지 확장하지 않음

## SOS314·315 포함

- 문제인식 → 자르기 → 문항분석 실제 공정 분리
- 전체 프로그램 진행률·경과시간·예상 남은시간 화면 통일

추가 SQL은 없습니다.
