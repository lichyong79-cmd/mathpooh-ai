# SOS297 · 개별 재생성 300초 정지 수정

SOS296에서 묶음 실패 직후 같은 함수 실행 안에서 개별 문항 재생성을 시작해,
앞 단계에 사용한 시간과 합쳐 Vercel 300초 제한을 넘기던 문제를 수정했습니다.

- 묶음 실패 시 개별 생성을 즉시 시작하지 않고 격리 모드만 저장합니다.
- 작업을 QUEUED로 돌려 다음 실행이 온전한 300초로 실패 문항 하나를 처리합니다.
- 개별 문항이 통과하면 즉시 보존한 뒤, 다음 문항은 다시 다음 실행으로 넘깁니다.
- 수동 실행도 정상 중간 종료를 FAILED가 아닌 QUEUED로 처리합니다.
- 죽은 GENERATING 작업 회수 시간을 15분에서 7분으로 단축했습니다.

추가 SQL은 없습니다.
