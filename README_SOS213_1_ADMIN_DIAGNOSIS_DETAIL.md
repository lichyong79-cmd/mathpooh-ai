# SOS213.1 관리자 진단 결과 상세 통합

SOS213 진단 앞단 정리본에 관리자 진단 결과 상세 확인 기능을 합쳤습니다.

- 관리자 `진단·훈련 진행현황`의 각 세션에 `결과보기` 버튼 추가
- 진단 문항별 정오답 / 학생 답 / 정답 / 풀이시간 / 사진제출시간 / 화면이탈 횟수 표시
- 진단 문항 원본 이미지 표시
- 학생 풀이사진 표시 및 새 창 크게 보기
- 풀이사진은 private `sos-solution-photos` bucket에서 관리자 API가 1시간 signed URL을 발급
- 시작/제출 시각은 세션 updated_at 대신 실제 문항 공개/답안·사진 제출 시각을 우선 사용
- 새 SQL 없음. SOS210에서 `supabase-v3.3-sos-diagnosis-evidence.sql` 실행 완료 상태를 전제로 함
