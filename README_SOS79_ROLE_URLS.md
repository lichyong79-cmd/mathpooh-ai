# SOS79 역할별 접속 주소

## 접속 구조

| 사용자 | 입력할 주소 | 로그인 방식 | 로그인 후 |
| --- | --- | --- | --- |
| 학생 | 서비스 기본 주소 `/` | 전화번호 + 비밀번호 | 학생 시험·OMR 페이지 |
| 관리자 | `/admin` | 관리자 이메일 + 비밀번호 | 관리자 페이지 |
| 학부모 | `/p` | 추후 학부모 인증 | 학부모 페이지(준비 화면) |

학생에게는 `/student-login` 같은 내부 주소를 안내할 필요가 없습니다. 서비스 기본 주소만 안내하면 로그인하지 않은 학생은 학생 로그인 화면으로 자동 이동합니다.

## 권한 분리

- 학생 계정은 `/admin`, `/problem-bank`, `/pdf-mapper`에 접근할 수 없습니다.
- `/admin`으로 접근한 비로그인 사용자는 관리자 로그인 화면으로 이동합니다.
- 관리자 로그인 화면에서는 학생 계정 로그인이 차단됩니다.
- 학생 로그인 화면에서는 관리자 계정 로그인이 차단됩니다.
- 로그인한 관리자가 서비스 기본 주소 `/`에 접근해도 학생 로그인 화면이 열립니다.
- 같은 브라우저에서 학생으로 로그인하면 기존 관리자 세션은 학생 세션으로 교체됩니다. 관리자 화면과 학생 화면을 동시에 확인할 때는 시크릿 창을 사용합니다.

## 배포 후 확인

1. 로그아웃 상태에서 서비스 기본 주소 접속 → 학생 로그인 화면
2. 로그아웃 상태에서 `/admin` 접속 → 관리자 로그인 화면
3. 학생 로그인 → 학생 시험 목록
4. 학생 계정으로 `/admin` 접속 → 학생 페이지로 복귀
5. 관리자 로그인 → 관리자 페이지
6. `/p` 접속 → 현재 학부모 준비 화면
