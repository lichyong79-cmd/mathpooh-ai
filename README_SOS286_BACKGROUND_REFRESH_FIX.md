# SOS286 — 학생 풀이 중 전체 로딩 화면 재등장 수정

## 증상
학생이 1차훈련 등 문제를 풀고 있는 중 갑자기 화면이 살짝 움직인 뒤
`진단·훈련을 가져오는 중입니다` 전체 로딩 화면이 나타날 수 있었습니다.

## 원인
AI 유사문항 생성 작업이 `QUEUED`/`GENERATING` 상태일 때 45초마다 `load()`를 호출했고,
`load()`가 무조건 `loading=true`로 전환하면서 현재 풀이 Runner를 화면에서 제거했다가 다시 올렸습니다.

## 수정
- `load(silent)` 모드 추가
- 최초 진입/사용자 동작에서는 기존 전체 로딩 유지
- AI 생성 45초 자동 확인은 `load(true)`로 실행
- 백그라운드 확인 중에는 전체 로딩을 띄우지 않음
- 백그라운드 확인 실패도 현재 풀이 화면을 방해하지 않음

따라서 학생이 진단/1차훈련/2차훈련/3제 굳히기/오답을 풀고 있는 동안
AI 상태 자동 확인 때문에 `진단·훈련을 가져오는 중입니다` 화면이 끼어들지 않습니다.
