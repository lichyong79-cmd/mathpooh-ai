# SOS266 학생 다음 단계 자동복구

- 1차 진단 완료 후 decision 문자열이 누락/구버전이어도 다음 단계가 막히지 않음.
- 2차 진단 완료 후 취약점이 있으면 1차훈련으로 자동 복구.
- 1차훈련 완료 후 decision 값이 없어도 정답률 90% 이상이면 3제 굳히기, 미만이면 2차훈련으로 자동 복구.
- AI 생성 job이 FAILED이면 더 이상 학생 화면을 막지 않고 재시도 버튼 노출.
- 재시도 시 기존 FAILED job을 QUEUED로 되살려 cron이 다시 생성하도록 처리.
- 과거 회차의 끊긴 학생도 회차를 열면 자동복구 시도.
