# SOS253 — 다음 단계 CTA + 누락 학습 자동복구

## 문제
- 완료 세션 뒤에 다음 학습이 생성돼도 학생이 이동할 버튼이 없는 화면이 존재.
- 1차훈련 통과 후 AI 3제 굳히기 생성이 실패하면 세션은 PASSED인데 자식 세션이 없어 '모든 학습 완료'로 잘못 표시됨.

## 수정
- 진단/훈련의 모든 완료 화면에서 다음 자식 세션이 있으면 명시적인 CTA 표시:
  - 2차 진단 하러가기
  - 1차 훈련 하러가기
  - 2차 훈련 하러가기
  - 3제 굳히기 하러가기
- 다음 단계가 원래 있어야 하지만 누락된 경우 '모든 학습 완료' 금지.
- 페이지 진입 시 누락된 다음 단계를 1회 자동 복구 시도.
- 자동 복구 실패 시 화면에 '3제 굳히기 준비하기 / 2차훈련 준비하기 / 2차진단 준비하기 / 1차훈련 준비하기' 버튼을 계속 노출.
- 새 API action `ensure_next`로 완료된 부모 세션에서 다음 세션을 안전하게 재생성.
- 생성 함수의 기존 중복 방지 로직을 그대로 사용하므로 반복 클릭/새로고침 시 중복 세션 생성 방지.
- 1차훈련 9/10 이상 통과라면 누락 복구 시 반드시 HOMEWORK 3문항을 생성.
- 진짜 최종완료는 HOMEWORK 완료 또는 2차훈련 완료 등 더 이상 기대되는 다음 단계가 없을 때만 표시.

SQL 없음.
