# SOS338 - 회차 중심 신청·응시 흐름 통합

## 최종 흐름
1. 회차 관리에서 운영 회차 생성
2. SOS 모집·신청 관리에서 모집 공개
3. 학부모는 회차만 신청하고 신청/결제/등록 상태 확인
4. 결제 확인 시 학생을 선택 회차에 등록
5. 관리자는 회차와 시험지를 별도로 연결
6. 학생 포털은 학생-회차-시험지 관계로 응시 권한 판단

## 화면 개편
- `실전모의고사 신청`을 `회차별 학생 등록`으로 변경
- 시험지 선택 드롭다운을 회차 선택 드롭다운으로 변경
- 메뉴를 기본 관리 → SOS 신청·회차 운영 → 시험지 운영 순으로 재배치
- `시험지 배정`을 `회차·시험지 연결`로 변경

## 분리 원칙
- SOS 신청은 기존 단일 실전모의고사 신청(`exam_registrations`)과 연결하지 않음
- SOS 결제 확인 시 시험지 등록행을 만들지 않음
- 시험지 연결 여부는 학부모에게 노출하지 않음
- 기존 응시·성적·SOS 학습 기록은 유지
