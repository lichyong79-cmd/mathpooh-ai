# SOS205 · 소단원별 8단계 난이도 연동

기준 버전: SOS203 (SOS204는 반영하지 않음)

공통 8단계:
1 2점 / 2 3점 / 3 어3 / 4 쉬4 / 5 적4 / 6 어4 / 7 준킬러 / 8 킬러

핵심:
- 학생에게 수학 전체 미터 1개를 두지 않음.
- 학생은 `과목 + 대단원 + 소단원`별로 각각 1.00~8.00 미터를 가짐.
- 세부개념/DNA는 별도 미터가 아니라 같은 소단원 안에서 문항 선택/취약 유형 매칭에 사용.
- 진단/훈련은 반드시 같은 소단원 안에서만 문항 선택.
- 진단 3문항 = 학생 소단원 미터 -0.9 / 현재 / +0.9.
- 훈련 10문항 = 안정화 2 / 적정 5 / 상향 3.
- 학생 소단원 미터는 실제 풀이마다 즉시 이동.
- 문항 난이도는 서로 다른 학생 20명 미만이면 DNA 난이도 고정.
- 20명째부터 해당 학생의 '같은 소단원 미터'와 실제 정오를 비교해 문항 난이도 이동.
- 같은 학생의 반복 풀이가 문항 표본수를 중복 증가시키지 않음.

설치:
1. SOS205 코드 배포
2. Supabase SQL Editor에서 `supabase-v3.1-subunit-difficulty-link.sql` 1회 실행
3. 이후 진단/훈련 UI에서 record-result를 호출하면 미터 자동 누적

주의:
- 소단원 분류가 비어 있는 문항은 난이도 연동 대상에서 제외하고 409로 알려줌.
