# SOS251 — 진단 만점 후 다음 단계 자동 이동

문제
- 진단 3문항을 전부 맞히면 서버는 AI 취약점 분석 후 2차 진단을 생성하고 있었음.
- 그러나 학생 페이지 activeId가 완료된 1차 진단에 남아 있어 학생에게 학습이 끝난 것처럼 보였음.

수정
- 같은 회차에 ASSIGNED / IN_PROGRESS / RETRAIN 세션이 있으면 완료 세션보다 열린 세션을 자동 선택.
- 1차 진단 만점 → AI 분석 → 약점 미발견 시 최저 바로미터 다른 영역의 2차 진단으로 자동 이동.
- 약점 발견 시 생성된 1차 훈련으로 자동 이동.
- 만점 진단 안내문을 '학습 종료'로 오해하지 않게 수정.
- SOS250의 AI 유사문항 이미지 및 전체 진행 UI 유지.
