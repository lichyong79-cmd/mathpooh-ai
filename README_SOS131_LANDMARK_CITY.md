# SOS131 LANDMARK CITY

학생 메인의 기존 SOS TOWER 3개를 대한민국 야경 지도 기반 SOS LANDMARK 화면으로 교체했습니다.

- 대수: 서울 63빌딩
- 미적분1: 서울 롯데월드타워(조금 뒤쪽 배치)
- 확률과통계: 부산 해운대 LCT
- 과목별 제출 완료 실전모의고사 최고 점수를 건물 완성도로 사용
- 최근 3회 과목별 평균을 도시 컨디션(맑음/보통/보수 공사 중)에 반영
- 건물 클릭 시 10단계 공사 진행 상세 모달 표시
- 기존 시험 신청, 응시, 결과, 학습분석 로직 유지

백분위 필드가 API에 추가되면 `src/app/page.tsx`의 `landmarkData` 계산에서 `attempt.score`를 해당 백분위 값으로 교체하면 됩니다.
