# SOS298 · AI 생성 작업 병렬 처리

- cron 한 번에 대기 작업을 최대 3개 선점합니다.
- 선점한 작업은 `Promise.allSettled`로 동시에 실행합니다.
- 한 작업이 실패해도 다른 학생의 작업은 계속됩니다.
- 겹친 cron 호출은 상태 조건부 선점으로 중복 생성을 막습니다.
- 대기 작업을 우선 처리하고, 남는 슬롯으로 7분 이상 멈춘 작업을 회수합니다.
- `SOS_AI_GENERATION_CONCURRENCY` 환경변수로 1~4 사이에서 동시 처리 수를 조절할 수 있습니다. 미설정 시 3입니다.

추가 SQL은 없습니다.
