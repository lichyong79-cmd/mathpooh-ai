# SOS226 · 공통 오답 엔진 + 단계별 UI

- 진단 3문항 / 1차 훈련 / 2차 AI 유사훈련 모두 같은 성적표-오답교정 흐름 사용
- 오답: 재도전1 실패 → 힌트1 / 재도전2 실패 → 힌트2 / 재도전3 실패 → 정답+핵심풀이 공개 후 확인 완료
- 진단 최초 정오답/풀이시간/풀이사진은 교정과 별개로 보존되며 AI 취약점 분석 근거로 사용
- 진단은 파랑, 1차 훈련은 초록, 2차 AI 유사훈련은 주황 계열로 구분
- 학생 화면은 단계 의미/다음 행동 안내 강화, 완료 과정 클릭 시 본인 결과/교정 이력 표시
- 관리자 결과 상세에 재도전 횟수, 사용 힌트, 교정 형태, 풀이사진, 풀이시간 표시
- SQL 변경 없음: 오답 시도/힌트/풀이확인은 기존 activity log로 기록
