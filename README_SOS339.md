# SOS339 학생 페이지 신청 제거

## 변경 내용

- 학생 화면에서 시험 신청, 신청 취소, 배정 대기, SOS 신청 안내를 제거했습니다.
- 학생에게는 회차 등록 또는 기존 직접 배정이 확인된 시험과 기존 응시 기록만 표시됩니다.
- 시험 접근 권한은 `회차-학생`과 `회차-시험지` 연결을 조합해 확인합니다.
- 학생 API의 시험 신청/취소 요청을 차단했습니다.
- `learning_cycle_students` 테이블이 아직 생성되지 않은 배포 직후에도 학생 로그인이 실패하지 않도록 처리했습니다.

## 운영 흐름

1. 학부모가 회차를 신청합니다.
2. 관리자가 결제를 확인해 해당 회차와 학생을 연결합니다.
3. 관리자가 별도 관리 화면에서 회차와 시험지를 연결합니다.
4. 학생은 자신이 등록된 회차의 시험만 확인하고 응시합니다.

## 필수 DB 반영

SOS338의 `supabase-sos338-learning-cycle-students.sql`을 Supabase SQL Editor에서 한 번 실행해야 회차별 학생 등록과 시험 접근이 정상 동작합니다.

## 검증

- Next.js 컴파일 성공
- TypeScript 검사 성공
- 정적 페이지 생성 단계는 로컬 Supabase 환경변수가 없어 중단됨
